## 大内密探零零幺之密信风云

#### 序章·任务下达

深夜，大内密探零零幺被长官从被窝里拎了出来。

“零零幺，有个光荣而艰巨的任务交给你。”

零零幺睡眼惺忪：“长官，什么任务要半夜交代？是不是皇宫的茅房又堵了？”

长官脸色一沉，然后掏出一份文件和一张皱巴巴的草稿：“敌国昨天送来一份**长篇报告，代号 `word1`**，表面上歌功颂德，实际上——我们的卧底在里头发现了一封**密信，代号 `word2`**。”

“那不是好事吗？密信呢？”

“就这张。”长官抖了抖那张草稿，“卧底拼死送出来的。但有个小问题——这密信和报告上的，可能有一个字不一样。”

零零幺愣了：“什么意思？咱们的人冒死偷密信，连字都没抄对？他是边跑边默写的吗？”

长官望向窗外，选择性失聪。

“所以我的任务是……”

“**把密信在报告里的位置标出来**。”长官把报告拍在桌上，“你要按顺序挑一串位置，把对应位置的字连起来，跟密信比对——**允许最多差一个字**。”

“那要是有好几种挑法呢？”零零幺举手，“比如密信是‘我爱你’，报告是‘我恨你我爱你’，我那我既可以挑第一、二、三个字的位置，也可以挑第四、五、六个字的位置——”

“交字典序最小的那组。”长官已经往门口走了，“找不到的话，提头来见。”

零零幺低头看了看那份十页的报告，又看了看手里十个字的密信。

他在心里骂了一句脏话。

------

#### 第一幕·逆向勘察

零零幺回到暗室，把报告往地上一铺，盘腿坐下。

十页报告，十个字的密信。暴力枚举所有组合？不行，不能用暴力。用暴力等于认输。堂堂大内密探，解个密信靠枚举？传出去还怎么在道上混。

必须贪心。

他靠着墙，闭上眼睛开始盘算：字典序最小，就是前面的位置编号越小越好。也就是说，从前往后，能早就早。密信第一个字，尽量在报告最前面找到；第二个字，紧接着往后找。能精确匹配就精确匹配，绝不轻易浪费那唯一一次"改字"机会。

逻辑满分。零零幺正要起身开干——

“等等。”

他又坐了回去。

“我怎么知道，现在该不该用掉那次改字机会？”

用了，后面可能不够凑；不用，眼前这个位置又对不上。左右为难，就像在赌坊里——牌已经摸了，但不知道该不该梭哈——敢不敢梭，取决于知不知道底牌是什么。

沉默了两秒。他把报告直接翻到最后一页。

“从后往前先算一遍不就完了。”

说干就干。零零幺把密信也倒过来，从最后一个字开始往前对，每对上一个字就记一笔。他给这套倒着摸出来的情报取了个名字，叫 `suf[i]`。

含义很直白：站在报告第 i 个位置往后看，能自然匹配掉密信的多大一段尾巴。

```python
# 报告长度 n，密信长度 m
n, m = len(word1), len(word2)

# 反向情报图
suf = [m] * (n + 1)  	# suf 全部初始化为 m（匹配不到，默认就是密信长度）
k = m - 1 				# 密信指针 k，从最后一个字开始
for i in range(n - 1, -1, -1):
    if k >= 0 and word1[i] == word2[k]:
        k -= 1 			# k 往前移一格（这个字对上了）
    suf[i] = k + 1		
```

一炷香的功夫，整份报告倒着扫完。零零幺往后一靠。

“妥了。有了这张图，从前往后冲的时候，每到一个位置，瞄一眼后面——够不够用，一清二楚。够用就敢改，不够就老老实实继续找。”

他站起来拍了拍灰，觉得自己此刻像个开了全图挂的将军。

虽然这个将军只带了一把暗器。

------

#### 第二幕·正面行动

零零幺觉得脑子前所未有的清醒。他给自己定了三条死规矩。

**铁律一：能对就立刻对。**

从前往后扫报告，若当前位置`i`的字正好等于密信需要的字 `word2[j]`，**必须立刻记下这个位置，写入答案**，密信指针`j` 往后推一位。

“字典序这玩意儿，第一位小者称王。此刻不下手，后面找到的同款字位置一定更大，整个序列就输了。这就好比排队领银两——你排第一个不去领，非得让后面的人先领，到你手里还能剩几个铜板？”

所以见到对的，立刻抢，一秒都别犹豫。

**铁律二：该改就果断改。**

如果字不同，但改字机会还没用，且**后续能成**——就在此处出手。

怎么判断“后续能成”？看`suf`情报——如果 `suf[i+1] <= j+1`，意味着从下一个位置开始，密信剩下的部分 `word2[j+1:]` 还能被报告后续完美匹配——既然后面的路走得通，眼前这个位置就是最佳出手时机。错过它，下一个能对上的位置只会在更后面，位置编号变大，字典序就输了。

就像牌桌上梭哈，手里有牌，桌上有路，该推的时候就推。犹豫的人活不到散场。

**铁律三：大招交过，再无特权。**

改字机会一旦用掉，后面的路没有任何花活。只能老老实实严格匹配——对得上就记，对不上就下一个，直到密信的最后一个字也找到为止。

“这就跟江湖比武一样，”他自言自语，“暗器只能放一次。放完了还没赢，那就等着被别人放倒。”

零零幺摊开报告，手指压在报告第一行，开始一个字一个字往后扫：

```python
# 2. 贪心构造
ans = []
j = 0
used = False
for i in range(n):
    if word1[i] == word2[j]:
        ans.append(i)
        j += 1
    elif not used and suf[i + 1] <= j + 1:
        # 使用修改机会：把 word1[i] 改成 word2[j]
        ans.append(i)
        j += 1
        used = True
    # else 否则跳过 i

	if j == m:  # 已经匹配完整个 word2
		return ans

return []  # 循环结束还没匹配完，无解
```

当最后一个位置落笔，他把笔一扔。

密信所有字，全部对上——每一步都是当时能抢到的最小编号。字典序最小，没毛病。改字机会只用了一次，用在了该用的地方。

“就这？倒着摸一遍，正着抢一遍。中间纠结那一下，全靠 `suf` 那张透视挂。”

他站起来，推门而出。

------

#### 结尾

长官接过那张写着位置的纸，看了半天：“零零幺，你确定这是字典序最小的？”

“确定。倒着摸底，正着贪心，三条铁律，一步没差。”

长官没说话，低头又看了一遍。然后抬起手，指着纸上第一个数字：“第一页。”

“第一页怎么了？”

长官把报告翻开，转过来给零零幺看。报告第一页赫然写着：

“机密报告，共十页。第一页为封面，正文从第二页开始。特此说明。”

整个房间安静了整整三秒。

“所以，”零零幺率先打破沉默，“敌国的报告，第一页是封面。”

“这不是重点。”长官的声音像从牙缝里挤出来的，“重点是你的算法，从封面里找出了密信。”

零零幺张了张嘴：“算法只认字，不认什么叫封面。”

“所以你的意思是——封面也算合法位置？”

“……那也不是不行？至少证明敌国文档做的挺规范。”

一个茶杯砸了过来。
