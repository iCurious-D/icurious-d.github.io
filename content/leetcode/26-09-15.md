## 回文套娃：从庞贝方阵到 DP

公元 79 年 8 月 24 日，维苏威火山爆发。岩浆吞没了庞贝，也把一座小城永远封存在了时间里。

近两千年后，考古学家从废墟中挖出一根柱子，上面刻着一个 5×5 的字母方阵：

```
S A T O R
A R E P O
T E N E T
O P E R A
R O T A S
```

横读、反读、竖读、倒竖读——全是同一句话。没人能确定它的原意，但所有人都看到了它的结构：**大回文套着小回文**。方阵正中间的 `TENET`——一个长度 5 的回文，被嵌套在更大的对称里。

庞贝人为什么刻下它，已经无从知晓。但回文并不只属于庞贝。数学家在数字里找它，生物学家在 DNA 里找它，物理学家在时间反演对称性里找它。

而今天，你坐在屏幕前，对着一条字符串找它。

------

#### 去掉首尾，还是回文

题目说每个回文"至少长 k"。最直接的反应是枚举所有长度 ≥ k 的回文，然后从中选不重叠的最大集合。

但回文有一个基本性质，庞贝方阵里的"大套小"正是它的直观体现：

> 去掉首尾，还是回文。

比如 `abccba` → `bccb` → `cc`，每一步砍掉首尾，每一步都是回文。

这意味着：**砍掉首尾得到的短回文，和原回文共享同一个对称中心，但占空间更少。**

假设你选了一个长度 L ≥ k+2 的回文。砍掉首尾，得到长度 L-2 的回文——仍然 ≥ k，完全落在原回文内部，不跟任何已选区间冲突。也就是说，换成短的，数量不会少，还可能给后面留出更多空间。

所以，要最大化数量，只需要**考虑最短的合法回文**。

那最短是多短？

- 长度至少为 `k`： `L ≥ k`。
- 长回文每次砍首尾都减 2。只要长度 `L ≥ k+2`，就还能继续砍——一个不能再砍的回文，必须满足"再砍 2 就不到 k"：`L - 2 < k`。

合起来： `k ≤ L < k + 2`。L 是整数，所以 L 只能是 **k 或 k+1**。

这两个长度就是所有合法回文的"最小粒度"。它们一奇一偶，刚好对应两种对称中心：

- 奇数长度回文，对称轴落在一个字符上，最小合法长度是 `k` 和 `k + 1` 中的奇数；
- 偶数长度回文，对称轴落在两个字符之间的缝上，最小合法长度是 `k` 和 `k + 1` 中的偶数。

一个管"字符中心"，一个管"缝隙中心"。两种对称方式，一个不漏。

------

#### DP：在每个位置做选择

现在问题缩小成：只看长度恰好为 `k` 和 `k+1` 的回文。

但"只看这两种"和"知道怎么选"之间，还有一步。

字符串天然从左到右。每扫描到一个位置 `i`，你都面临一个选择：

> 要不要选一个以 `s[i-1]` 结尾的回文？

不选：直接继承前一个状态。

选：检查以 `s[i-1]` 结尾、长度为 `k` 或 `k+1` 的子串是不是回文。

经典的"每一步做局部选择，目标是全局最优"——DP 的主场。

定义 `f[i]` = `s[:i]` 里最多能选多少个不重叠回文。每个位置 `i` ，三种情况——取最大：

- 不选：`f[i] = f[i-1]`
- 选以 `s[i-1]` 结尾、长度 `k` 的回文：前提是 `s[i-k:i]` 是回文。它占掉区间 `[i-k, i-1]`，前面只能用到 `s[:i-k]`，即 `f[i-k]`：`f[i] = max(f[i], f[i-k] + 1)`
- 选以 `s[i-1]` 结尾、长度 `k+1` 的回文：前提是 `s[i-k-1:i]` 是回文。它占掉区间 `[i-k-1, i-1]`，前面只能用到 `s[:i-k-1]`，即 `f[i-k-1]`：`f[i] = max(f[i], f[i-k-1] + 1)`

循环从 `i = k` 开始；检查长度 `k+1` 时需满足 `i > k`，避免下标越界。

```python
def maxPalindromes(s: str, k: int) -> int:
    n = len(s)
    f = [0] * (n + 1)
    for i in range(k, n + 1):
        f[i] = f[i - 1]
        if s[i-k:i] == s[i-k:i][::-1]:
            f[i] = max(f[i], f[i-k] + 1)
        if i > k and s[i-k-1:i] == s[i-k-1:i][::-1]:
            f[i] = max(f[i], f[i-k-1] + 1)
    return f[n]
```

时间 O(nk)：n 个位置 × 切片比较 O(k)。空间 O(n)：一个一维数组。

------

#### 尾声：

"Palindrome"来自希腊语：palin（再次）+ dromos（奔跑）——再跑一遍。正着跑，反着跑，路径重合。

两千年前，庞贝石匠在石柱上刻下 Sator Square；四十亿年前，原始海洋里的 RNA 分子复制出第一段正反读都一样的序列。他们做的事，和你刚才一样：在混沌的序列里，找到对称的那一小段。

区别只是工具。

石匠用凿子，RNA 用碱基对，而你——用 `s[i-k:i] == s[i-k:i][::-1]`。
