## 端点重合？不存在的，我加了 k-1 个虚拟位置

看到"端点可以重合"，我就知道今天这题不单纯。

> `n` 个点排成 `0 ~ n-1`，找恰好 `k` 个不重叠线段，每条至少盖两个点。**端点可以重合**。

`k` 条线段，`2k` 个端点。如果这 `2k` 个端点能**严格递增**地排队，那这题就是送分题：从 `n` 个位置里选 `2k` 个，组合数 `C(n, 2k)`，收工。

但"**端点可以重合**"——意味着允许相等。翻译成数学：

```
设第 i 条线段的起点 sᵢ、终点 eᵢ：
0 ≤ s₁ < e₁ ≤ s₂ < e₂ ≤ … ≤ sₖ < eₖ ≤ n-1
```

一堆 `≤` 混在 `<` 里，像火锅里混进了香菜，有人觉得没事，组合数看了直接掀桌——毕竟它只吃严格递增。

能不能把 `≤` 干掉？

------

#### 祖传偏移术

老刷题人有个把 `≤` 变成 `<` 的祖传偏移术：**给第 i 条线段整体加 i-1。**

说白了：第 1 条线段原地不动，后面的线段依次往右挪，越靠后挪得越远——第 1 条加 0，第 2 条加 1，第 3 条加 2……第 `k` 条加 `k-1`。

写成数学形式就是：

> 原式： `0 ≤ s₁ < e₁ ≤ s₂ < e₂ ≤ s₃ < e₃ ≤ … ≤ sₖ < eₖ ≤ n-1`
> 给第 `i` 条线段整体加 `i-1` 后：
> `0 ≤ s₁ < e₁ < s₂+1 < e₂+1 < s₃+2 < e₃+2 < … < sₖ+k-1 < eₖ+k-1 ≤ n+k-2`

看交界处：

- 原来 `e₁ ≤ s₂`，偏移后变成 `e₁ < s₂+1`；
- 原来 `e₂ ≤ s₃`，偏移后变成 `e₂+1 < s₃+2`；
- 原来可能相等的 `eᵢ` 和 `sᵢ₊₁` 现在至少差 1，每一处 `≤` 都被撑成了严格 `<`。

最后 `eₖ ≤ n-1` 加上偏移后变成 `eₖ+k-1 ≤ n+k-2`。数轴从 `[0, n-1]`（n 个位置）膨胀到 `[0, n+k-2]`（n+k-1 个位置）。多出来的 k-1 个位置，就是那 `k-1` 个 `≤` 被撑开时产生的"裂缝"。

所有端点严格递增——正好是组合数最爱的形状。从 `n+k-1` 个位置里选`2k` 个端点，`C(n+k-1, 2k)`。

```python
def numberOfSets(n: int, k: int) -> int:
    return comb(n + k - 1, 2 * k) % (10**9 + 7)
```

------

#### 复盘

折腾半天，实际就干了一件事：**把 `≤` 偷偷换成 `<`**。

手段也很朴素：在“可以相等”的接缝处塞上 1 格偏移，把 `≤` 撑开。`k` 条线段有 `k-1` 个接缝，就塞 `k-1` 个偏移。`≤` 一没，组合数就可以支棱起来了。

这招在生活里也很常见：

- 数据库里两条记录 timestamp 撞了？后面那条 `+1ms`。
- 游戏里两个角色卡同一个格子？后面那个被物理引擎弹开。
- 食堂排队贴太近？阿姨吼一嗓子"往后站"，本质上就是给你加了个偏移量。

下次再被阿姨吼，别生气。她不是在凶你，她是在对你施展祖传的 **≤ 消除术**。
