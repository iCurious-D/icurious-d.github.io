## ONE PIECE 番外特别篇 ～ 娜美大小姐绝不允许分赃有零头！伟大航路·整除之岛大清点 ～

大海贼时代。无数海贼为追寻那传说中的大秘宝，扬起骷髅旗，把命押在风浪里，一头撞进伟大航路。

而在草帽一伙的万里阳光号上，悬着一条比海贼旗还硬的铁律——财宝，归娜美管。

不服的，可以先去问问她那只曾把路飞一拳打进甲板三寸深的拳头。

------

**【第一幕 · 海图即战场！！】**

这天午后，阳光号驶进一片星罗棋布的海域。阳光砸在海面上，碎成万千金鳞；而那些散落其间的岛屿，轮廓在光里隐隐反着金币的色泽——

一整片。整整一片。**会发光的海**。

“娜美——！”路飞整个人已经挂上船舷，橡胶脖子伸得比桅杆还长，口水流成瀑布：“财宝岛！一整片！全抢了吧——！！！”

**咚！！**一记铁拳精准砸下，路飞头顶当场鼓起一个熟透的包，甲板裂开蛛网纹。

娜美额角青筋"蹦蹦"直跳："上次你'见者有份'，为了最后一枚金币，跟索隆在甲板上砍了三天三夜，把主桅杆都拆了——修桅杆的钱谁出？啊？！"

路飞揉着头，咧嘴笑得没心没肺："可我是要成为海贼王的男人啊！"

"海贼王，也得先学会分钱。"娜美长发猎猎，眼神锐利得能切开海浪，"听好了，本航海士的铁规矩——**一座岛的财宝总量，必须能被船上 k 个伙伴一、个、不、差地平分**。除得尽，才抢；除不尽，金山也给我原路滚回去！"

索隆在旁边打了个哈欠："至于吗。全搬上船不就得了。"

"至于。"娜美冷笑，"总量除不尽 k，最后一枚金币你掰几瓣？你能把它劈成原子吗，绿藻头？"

"……我砍得断。"

"你砍断的是伙伴之间的信任！！"

索隆罕见地闭了嘴。

娜美"啪"地一声摊开航海图——一张 `m × n` 的网格海图铺在甲板上。海面（值为 `0` 的格子）空无一物；只有**上下左右四方向相连**的财宝堆，才算同一座岛。每格财宝都标着价值——2 枚金币、5 颗宝石，全是正整数。一座岛就是一个连通块，岛的总价值就是连通的所有格子加起来的结果。

"任务很简单。把每一座岛都登一遍，算清全岛总和，数出**有几座岛能被 k 整除**——”

娜美抬起头，金瞳里燃着火光：

“**这些，才是我们草帽一伙，能堂堂正正公平瓜分的岛！**”

------

**【第二幕 · 橡胶橡胶之·深度优先探宝枪！！】**

规矩定了，接下来是怎么清点。

娜美环视一圈，目光"唰"地锁定正揉着脑袋的路飞——这橡胶人，别的用处没有，当个探针倒是天生丽质。

"路飞，就你了。站在岸边别动，"她把账本"啪"地拍在他胸口，"用你的橡胶手臂，给本大小姐把整座岛扫一遍！"

路飞咧嘴一笑，抬手压了压草帽。那一刻，海风骤停——

"交给我！**橡胶橡胶之·深度优先探宝枪（DFS）**！！" 他的手臂"咻"地弹射出去，三步连环，一气呵成：

- **第一步，抓住就记账**：手臂够到哪一格，那格财宝的价值立刻计入娜美的总账。
- **第二步，记完就搬空**：财宝一被攥住就顺手搬空，原地只剩一个空坑。这就是**记号**——待会儿手臂乱窜时摸到 `0`，就知道"这儿薅过了"，绝不重复抓第二遍。
- **第三步，四方向突进**：抓住一格后，手臂自动朝上下左右四个方向继续伸展。只要隔壁还有没被搬空的财宝，橡胶就一头扎过去，`dfs` 递归深入，把整座连通岛的财宝全拖回来累加。

（旁白）"不漏一格，不薅两遍。伸出去是深入，缩回来是结算——这，就是娜美大小姐的强迫症。啊不，实力。"

一座岛走完，娜美的账本上就多出一个数字——全岛财宝总量。她再飞快做个除法：**能被 k 整除吗**？

- **能**。娜美的眼睛"唰"地变成两枚金币，"插旗！这座岛本大小姐承包了！今晚开宴会！" 路飞兴奋地举起双手："宴会——！"
- **不能**。她面无表情转身，"扬帆，走人，当我没来过。" 路飞伸长的手臂"啪叽"一声垂在了地上，差点把路过的乌索普绊个跟头。

罗宾端着咖啡，微微一笑：“有趣。把每座岛一路摸到底，再回溯累加——这不就是深度优先搜索么。”

乔巴眼睛一亮：“深、深度优先？听起来好像潜水病啊！要吃药吗？！”

“不，是 DFS。”弗兰奇摆了个 SUPER 姿势，“遇到陆地就一头扎进去，四面八方递归到底，撞到墙再退回来——SUPER——！”

```python
def countIslands(grid: List[List[int]], k: int) -> int:
    m, n = len(grid), len(grid[0])
    
    # 橡胶橡胶之·深度优先探宝枪：手臂抓住一格，自动向四方递归，扫完整座连通岛
    def dfs(i: int, j: int) -> int:
        res = grid[i][j]      # 抓住就记账：这格财宝的价值，顺着橡胶传回岸边总账
        grid[i][j] = 0        # 抓住就搬空：原地留个坑当"已薅"标记，手臂绕回来也不会重复抓
        for x, y in [[i + 1, j], [i - 1, j], [i, j + 1], [i, j - 1]]:  # 四向突进：上下左右
            if 0 <= x < m and 0 <= y < n and grid[x][y]:
                res += dfs(x, y)   # 递归深入，把整座连通岛的财宝拖回来
        return res

    ans = 0
    for i, row in enumerate(grid):
        for j, x in enumerate(row):
            # 发现新岛入口（还有财宝），派路飞进去扫一遍
            if x and dfs(i, j) % k == 0:  # 娜美大小姐的整除审判
                ans += 1

    return ans
```

> 娜美的小黑板：
>
> 1. **主循环负责“找入口”**：扫到非 `0` 的格子，说明发现新岛，派路飞进去。扫到 `0` 就跳过——那是薅过的坑或本来就是海面。
> 2. **dfs 负责“扫全岛”**：抓一格、记一笔、置 `0`、往四边递归。返回值就是全岛总和。
> 3. **置 0 就是 visited**：不用额外数组，省空间，还顺手防了重复访问。

罗宾：“每格最多进一次 dfs，时间 `O(m * n)`。很优雅。”

娜美点头：“递归深度最坏 `O(m * n)`——不过海图再大，也就 `m * n <= 10^5`，路飞的手臂还够用。”

【**第三幕 · 绿藻头大迷航！没有记号的剑士！！**】

“喂喂，这有什么难的。”索隆扛起三把刀，打了个哈欠，“不就是登岛、搬宝、做个除法吗。娜美，随便指一座，我去。”

娜美挑眉：“你？路痴清点财宝，我怕你把整片海域的岛都算成同一座。”

“少废话。”索隆已经跳上小艇，“指。”

乔巴指着远处：“那座岛好长好长啊，从海图这头一直到那头！”

索隆眼睛一亮：“长岛？我走直线从来不迷路。我去。”

娜美：“你给我站住——”

太迟了。小艇已经蹿出去了。

一个钟头后，娜美一看——索隆那座，一格财宝都没少，人也不见了。再找到他时，他正在三里外的另一座小岛上，对着一堆搬空的财宝发呆。

“你到底在干嘛！！”娜美暴跳如雷，“那座岛你搬完了吗？你怎么会在这儿？！”

"我绝对没迷路。"索隆一脸严肃，"是这座岛，自己漂过来的。"

"岛怎么会自己漂啊！"

真相是——索隆登岛之后，走了三步就忘了自己踩过哪儿。他没做任何记号，全凭一双腿和“我绝对没迷路”的钢铁信念，在岛上来来回回地走，反反复复在同几格财宝之间打转，最后索性一头扎进腹地，越走越深，走着走着就从另一个方向走进了海里，稀里糊涂漂到了隔壁岛。

"看清楚了，绿藻头。"娜美一把揪住他的领子，"路飞每抓一格都搬空留坑，这叫**标记已访问**，这才不会重复、不会绕圈。你倒好，什么记号都不做，光靠一双腿——走到哪忘到哪，原地鬼打墙，把自己绕进海里！”

罗宾慢悠悠补刀：“同一格反复进 `dfs`，递归永远回不来。”

索隆似懂非懂地点头："……所以我迷路，是因为没像路飞那样，留个记号？"

“对！！”

“那我现在回去补记号。”

“补你个头！你人都漂到隔壁岛了！” 娜美一拳砸下。

**咚！！**索隆头顶鼓起一个包，和路飞头上那个对称。

**【彩蛋 · One Piece 除不尽怎么办】**

当夜，整除之岛上，篝火熊熊。

山治端出大餐："娜美桑～为您精准无双的算术，干杯～！"
布鲁克举杯："哟嚯嚯嚯，虽然我已经没有胃可以装了。"

路飞一边塞肉一边含糊地问："喂娜美，那……One Piece，能被我们平分吗？"

全场安静。

娜美手指飞快演算，脸色越来越白："One Piece 只有一个，我们船上有 k 个人，一个 ÷ k……除、除不尽，余数是 1……"

"也就是说，"罗宾托腮微笑补刀，"等找到大秘宝那天，为了这一个除不尽的零头，草帽一伙会当场解散、互相残杀呢。啊啦，真期待。"

"不要说这种不吉利的话啊罗宾——"

路飞却咧嘴一笑，举起拳头，眼睛亮得像燃烧的火焰："那就简单了！等我当上海贼王，第一件事——把 k 改成 1！One Piece 全是我的！嘻嘻嘻！"

娜美合上账本，深吸一口气，露出一个比哭还难看的商业假笑：

"路飞。你再说一遍，我就把你那份肉，mod 成 0！！！"
