## **不用并查集，一把菜刀就够了**

> 本文纯属虚构，如有雷同，那一定是菜市场真有人这么干。

**序章：差评如雪**

庙街辣椒市场，摊位从 0 到 n-1 一字排开，辣度随缘摆放，堪称辣度布朗运动。

顾客从 0 号摊进街，第一口咬中魔鬼椒，当场抬走。点评网站差评如雪：

"毫无层次感，纯纯暴击。"

"建议老板先学过字典序再摆摊。"

管理处连夜贴出 KPI：

> 二十四小时内，把整条街辣度序列排成**字典序最小**。
> 规则：**辣度差 ≤ limit 的两个摊主，可以互换摊位，次数不限**。
> 否则，没收辣椒，改种青椒！

我——阿星，前大厂码农，被裁后躲进菜市场卖甜椒——一看这规则，职业病当场发作：

"辣度相近的能互相换位……换的次数不限……这不就是**按差值连通的帮派**吗？帮派内部随便折腾，帮派之间老死不相往来！"

《码农的自我修养》第一章怎么写的来着？**先看清谁能跟谁玩，再谈怎么玩。**

我正盘算着，街尾传来一声狂笑，把整条街的狗都吓精神了。

------

**第一幕：邪神踢馆**

"全市场谁敢动我的魔鬼椒？！"

火云邪神一脚踹翻自己的招牌，辣度登记表上赫然写着：1000000。

"我辣度一百万！谁跟我差 ≤ limit？没有！我——焊死在原地！"

他挑衅地看向我："甜椒佬，辣度常年 0 战力，你有意见？"

我放下甜椒，拍了拍围裙上的土。"邪神，你的辣椒辣嘴，我的逻辑辣脑。要不比划比划？"

人群里有人起哄："有本事你把整条街排明白啊！"

我抄起喇叭："各位摊主，都到街心集合！第一步——**全体按辣度从小到大排队，但每个人把原来的摊位号牌挂在脖子上，别弄丢了！**"

王大妈一挥手："排完队按新顺序领摊位不就完事了？还挂什么号牌，这不是多此一举吗？"

"急什么，排队只是第一步，把辣度相近的人凑到一起。"我指了指那一片号牌，"这些牌子才是命根子。"

"至于真正的主角——"我从案板上抄起一把菜刀："——是这个。"

人群倒吸一口凉气。

------

**第二幕：一把菜刀，切出帮派**

我提着菜刀沿队伍走，只比较**相邻两人**：

- 辣度差 ≤ limit → "拉手！同一帮派！"
- 辣度差 > limit → 手起，刀落，"断！从此各过各的！"

队伍被切成若干段，段内辣度相近，段间天堑难越。

二大爷从队尾探出脑袋："凭啥只看相邻？我隔三个位置的老李，照你这么说，我俩还换不了了？"

"二大爷，讲科学。排完队，相邻的就是差得最小的。**连相邻的都差超过 limit，隔更远的只会差更多。**裂缝一旦出现，就是天堑，左右两边谁也甭想跨过去。"

二大爷又问："那拉了手的段里，最前和最后也可能差挺远啊？能换位？"

我嘿嘿一笑："**朋友的朋友是朋友**——我不认识你，但我兄弟认识你，中间有人搭桥就成——段里相邻的都能搭上线，那整段就是一张网，谁都能到谁那儿去。"

火云邪神环顾四周，发现自己孤零零杵成一段，嘴硬道："哼！我一个人就是一段！我是独狼！"

"对，独狼。"我把刀往案板上一插，"原地站好，一步不许动。**跨段不可交易——这就叫限差交换。**"

------

**第三幕：帮派内部，菜鸡前置**

"切完段，现在每个段都是一个帮派。"我清清嗓子，"接下来，发牌。"

众人围过来，王大妈凑最前："发什么牌？要打牌？"

"不是打牌，是发摊位牌。"我指了指王大妈脖子上的号牌，"每个段，两步走：

**第一步**，段里所有人把原摊位号牌摘下来，从小到大排成一排。
**第二步**，段里的辣度值早就按升序排好了，直接按序领牌——**最小的辣度领最小的摊位号，次小的辣度领次小的摊位号**，依此类推。"

当场演示，拿管理处给的示例 2 开刀：`nums = [1,7,6,18,2,1]`，`limit = 3`。

- 排队（括号里是原摊位号）：1(0)，1(5)，2(4)，6(2)，7(1)，18(3)。
- 切段：2 和 6 差 4 > 3，砍！7 和 18 差 11 > 3，砍！
- 出来三个帮派：
  - A 帮：辣度 [1,1,2]，原摊位号 [0,5,4] → 下标排序 [0,4,5]，发牌 1(0),1(4),2(5)
  - B 帮：辣度 [6,7]，原摊位号 [2,1] → 下标排序 [1,2]，发牌 6(1),7(2)
  - C 帮：辣度 [18]，原摊位号 [3]，发牌 18(3)

拼起来就是 `[1,6,7,18,1,2]`。

王大妈掰着指头问："听着是挺整齐……可凭啥这么发牌，字典序就最小？"

"因为字典序是从门口一位一位比过去的。每个摊位只能从**自己帮派**里拿辣度——帮派外的够不着，帮派内的不客气。每个位置，都在自己能触及的范围内选最小的填上，一路贪到底。各段互不串门，**局部最优直接拼成全局最优**。"

火云邪神听完更不服了："绕这么大圈子，这不就是排序吗？跟全局排序有什么区别？"

"区别在于——你，动不了。"我指着队伍，"全局排序会把你从 3 号摊挪到 5 号摊，但现在有`limit` 限制，你就只能在自己那一亩三分地里待着。全局排序的前提是人人连通；你——零人脉。"

```python
def lexicographicallySmallestArray(nums: List[int], limit: int) -> List[int]:
    n = len(nums)
    # （辣度，原摊位号）按辣度从小到大排队
    pairs = sorted((num, i) for i, num in enumerate(nums))
    
    res = [0] * n
    i = 0
    while i < n:
        # 切段：相邻辣度差 <= limit 就一直拉手，否则一刀砍断
        j = i
        while j + 1 < n and pairs[j + 1][0] - pairs[j][0] <= limit:
            j += 1

        # 本帮派：原摊位号排好序，辣度值已经升序
        indices = sorted(pairs[k][1] for k in range(i, j + 1))
        values = [pairs[k][0] for k in range(i, j + 1)]

        # 发牌：最小的摊位号，领最小的辣度
        for k, idx in enumerate(indices):
            res[idx] = values[k]

        i = j + 1

    return res    
```

排序 O(n log n)，切段一趟 O(n)，段内摊位号排序最坏 O(n log n)，总共 O(n log n)。

**彩蛋：**

第二天，市场验收通过。顾客从微辣一路吃到变态辣，点评区画风突变：

"好有层次感！第一口甜椒，温柔得像做梦！"

"渐进式的辣！这才是真正的辣椒市场！"

记者举着话筒冲过来："阿星师傅！别人都在喊并查集，你为什么一把菜刀就解决了？"

我还没来得及开口，王大妈从旁边挤过来："这有啥稀奇的？排队、切段、发牌，三岁娃娃都会！"

记者扶了扶眼镜："......这位阿姨，如果我没理解错——" 他的气质突然一变，"你说的应该是**差值约束下的连通块划分**。排序之后，区间图退化成连续段，相邻差超限的位置就是割点，一次线性扫描完成划分，再按下标贪心回填——严格来说，这不是刀法，这是**容差约束下的离线排列重构**……"

王大妈张了张嘴，转头看我，眼神里写满了“这人怕不是有病”。

我手里的菜刀还举在半空，忘记放下来。

沉默三秒。我问：“大哥……您以前写代码的？”

记者："大厂后端，去年被裁了。HR 当时管这叫'结构优化'，我还没太听懂——今天看了你的刀法才想明白，原来我就是那个被一刀切出去的独立段。"

火云邪神推着甜椒车从旁边路过，头也不回地丢下一句："我都跟你说了，这行不好干，不如卖辣椒。"
