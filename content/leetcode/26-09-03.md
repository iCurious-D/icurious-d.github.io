## 昨天随便抓个奇数，今天得查最小值

> 昨天的我们还在为恒真命题欢呼，今天策划反手就是一个热更新：减法结果必须 ≥ 1。
> 工具人不能随便抓了，得挑个“最菜”的。

**第一步：昨天的套路，今天卡哪儿了？**

昨天的操作简单粗暴：只要有奇数，随便抓一个奇数当“工具人”，所有偶数减它变奇，打卡收工。

今天的题目多了个补丁：`nums1[i] - nums1[j] >= 1`。

这意味着减法结果必须为正。如果工具人奇数太大，某个偶数比它还小，那么 `偶数 - 奇数` 就会变成负数，当场崩盘。所以，要让所有偶数都减得动它，这个工具人奇数必须比所有偶数都**小**。

**第二步：全场最“菜”的奇数**

> 比所有偶数都小的奇数，只能是整个数组的**最小值**。

于是，当数组的最小值是奇数时，它就是天选工具人：所有偶数都比它大，减出来必然 ≥ 1，且奇偶性翻转。完美，直接启动全奇策略：

- 所有偶数：减去这个最小奇数 → 正数，奇偶性翻转为奇；
- 所有奇数：保持原样，本来就是奇数。

**第三步：一个奇数都没有？直接躺赢**

整个数组全是偶数，那它本来就达成"全偶"目标了。照抄一遍，返回 True。

**第四步：有奇有偶，最小却是偶数？这波寄了**

此时，所有奇数都比这个最小偶数大。

走全奇路线：最小的偶数减任何奇数都变负，这队根本带不动。

走全偶路线呢？奇数想变偶数，得减去一个比它更小的奇数（奇 − 奇 = 偶，且差要为正）。可奇数堆里最小的那个奇数已经无人可减，只能原地干瞪眼。

两头堵死，只能老实返回 `false`。

**结论**

| 情况                   | 走哪条路                     | 答案  |
| ---------------------- | ---------------------------- | ----- |
| 全是偶数               | 本来就全偶，躺赢             | True  |
| 有奇数，且最小值是奇数 | 最小值奇数当工具人，全队变奇 | True  |
| 有奇数，但最小值是偶数 | 工具人失效，全奇全偶都走不通 | False |

```python
def uniformArray(nums1: List[int]) -> bool:
    # 要么全偶，躺赢
    # 要么最小值是奇数，它来当“工具人”
    return all(num % 2 == 0 for num in nums1) or min(nums1) % 2 == 1
```

> 昨天：无条件恒真，随便拉个奇数就能救场；
> 今天：有条件恒真，最菜的是奇数才能带飞。
> 策划：本次热更新修复了『躺赢』漏洞。
