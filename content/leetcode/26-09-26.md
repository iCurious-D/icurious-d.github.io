## 圆括号：我在 Unix 当工具人，在 LeetCode 当 key

给一串 `(name)is(age)yearsold`，再给一张对照表，让你把括号里的东西查表换掉，查不到就填 `?`。

说白了就是一次变量展开——Shell 五十年前用 `$VAR` 玩这套，今天力扣把美元符号换成了圆括号，仅此而已。

至于怎么实现这个替换，从手抠字符到正则，再到模板引擎，恰好是脚本语言处理字符串替换的半个世纪进化史。

------

#### 1979：Bourne Shell——手工抠字符

1979 年，Stephen Bourne 在贝尔实验室捣鼓出 Bourne Shell，给了程序员 `$VAR` 和 `${VAR}`。变量展开从此成了脚本语言的标配。

但那个年代的 Shell 可没有"批量替换模板"这种奢侈功能。想展开变量？自己写 `while read` 循环，一个字符一个字符地抠。没有工具，没有库，一双手就是全部家当。

对应到这道题，就是最朴素的手工遍历：

```python
def evaluate(s: str, knowledge: List[List[str]]) -> str:
    knowledge_dict = dict(knowledge)
    res = ''
    left = -1
    for i, ch in enumerate(s):
        if ch == '(':
            left = i
        elif ch == ')':
            res += knowledge_dict.get(s[left+1:i], '?')
            left = -1
        elif left < 0:
            res += ch
    return res
```

`left` 负责记住左括号在哪，遇到 `)` 就切片查表拼进去；`left < 0` 的意思是"我现在没在括号里，别拦我"，普通字符直接追加。

一遍扫描，又快又稳。那个年代的程序员，就是靠这种手艺活吃饭的。

------

#### 1987：Perl ——正则统治一切

1987 年，Larry Wall 发布了 Perl。这位老哥是语言学家转行写代码，信仰是 TIMTOWTDI ——“做一件事不止一种方法”。他设计 Perl 的初衷之一，就是让文本处理不再像 Shell 脚本那样笨拙。

Perl 把正则表达式正式扶正为脚本语言的一等公民。从此，“找模式 → 替换”这种活，一行正则碾压。

Python 的 `re` 模块，就是继承了 Perl 的这份遗产：

```python
def evaluate(s: str, knowledge: List[List[str]]) -> str:
    knowledge_dict = dict(knowledge)
    return re.sub(r'\((\w+)\)', lambda m: knowledge_dict.get(m.group(1), '?'), s)
```

`re.sub` 负责扫描，`\((\w+)\)` 负责捕获括号里的 key，`lambda` 负责查表换值。三个零件，一行装配。

你不再告诉计算机“一个字符一个字符地找”，而是告诉它“我要的是这个模式”——从命令式到声明式，思维层次直接拔高一级。短、帅、骚，写完感觉自己就是 Larry Wall 本人。

不过，正则一长，可能连写的人自己都看不懂——就像正则界的经典名言：

“我有个问题，于是我用正则解决了它。现在我有两个问题。”

------

#### 2008/2011：Python——模板引擎接管

2008 年，Python 2.6 发布，`str.format()` 正式登场。脚本语言终于有了内置的模板引擎。你不用再手动抠字符，也不用写正则，把占位符写成 `{key}`，引擎替你干活。

三年后，Python 3.2 带来了 `format_map()`，专门为“拿字典填模板”这种场景设计。对应本题，思路就是**借壳**：`(` 换 `{`，`)` 换 `}`，然后 `format_map` 接管一切。

```python
def evaluate(s: str, knowledge: List[List[str]]) -> str:
    knowledge_dict = defaultdict(lambda: '?', knowledge)
    return s.replace('(', '{').replace(')', '}').format_map(knowledge_dict)
```

`defaultdict(lambda: '?')` 保证查不到的键返回 `?`——就像 Bash 里的 `${VAR-?}`，但更优雅：不报错，只给你一个冷静的问号。

两行代码，不碰索引，不写循环，堪称最 Pythonic 的写法。

不过，这招有个前提：`s` 里不能含有 `{` 或 `}`。否则 `replace` 一换，`format_map` 会把原来的花括号当成占位符继续解析，当场翻车。好在本题的 `s` 由小写字母和括号组成——出题人替你填了坑。

#### 彩蛋：野史——请勿当真

话说 Unix 创世之初，贝尔实验室里烟雾缭绕。

Ken Thompson 和 Dennis Ritchie 蹲在 PDP-11 旁边啃披萨，突然吵了起来：

Thompson：“变量展开必须用 `$`！因为 `$` 像钱，程序员都爱钱。”

Ritchie：“放屁，`()`才有哲学！包围即展开，`(name)` 多直观！”

毫无疑问，Thompson 赢了。

于是 `$name` 成了 shell 变量，`${name}` 成了带花括号的贵族写法。而圆括号 `()` 被发配去当子 shell 和命令替换。

至于力扣 1807 为什么用圆括号当键？

大概是因为出题人觉得，圆括号在 shell 里当了半辈子执行命令的工具人，总该让它当一回主角吧。
