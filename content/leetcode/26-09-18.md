## **别惹字母帮，惹一个来一窝**

字符串一条街，26 个小写字母各占山头。从第一次露脸到最后一次收工，那就是它的堂口范围。

规矩贼横：你的子串里只要出现某个字母，全街同字母的字符都得进这个子串。一个都不能少。

比如，你本来只想拉 `d` 一个入伙，结果 `d` 把街头到街尾的兄弟`d`全摇来了：“我的人要么全在，要么全不在！”

更要命的是，你被迫把 `d` 的堂口范围整个划进来之后，里面要是混有其它帮派字母，比如 `a`、`f`，那它们也得全家到齐。一个帮派牵扯另一个帮派，连锁反应根本停不下来。

你的目标是：从这条街上挑出**尽可能多的非空子串**。被挑中的每个子串都得满足：

- **闭包**：这个子串里出现的帮派，全街的本帮小弟都得罩得住，一个不能漏。
- **互不重叠**：子串和子串不能压线，你圈你的，我圈我的。

如果挑出的子串数量一样多，那就再比总长度：所有挑中的子串加起来越短越好。

返回这些子串，顺序随意。

------

#### 第一步：摸清每个帮派的堂口

先摸清每个字母的堂口范围——第一次和最后一次出现的位置。

```python
first = {}
last = {}
for i, c in enumerate(s):
    if c not in first:
        first[c] = i
    last[c] = i
```

比如 `"adefaddaccc"`：

- `e` 和 `f` 是独行杀手，`first == last`，一个人一个坑，干净利落。
- `c` 独占 `[8, 10]`，内部全是自己人，不触发任何连锁。
- `a` 就不一样了，堂口 `[0, 7]`，里面裹着 `d、e、f` 三个帮派。选 `a` 就等于把 `[0, 7]` 整段包圆，连 `d、e、f` 一起——场面直接拉满，8 个字符。

堂口边界摸清了，后面才能判断：圈一个子串，到底会牵连出多少兄弟。

------

#### 第二步：从每个堂口出发，滚出最小合法闭包

不是每个字符都能当子串的老大。

一段合法闭包的左端点，一定是某个字符的 `first`。不然左边还漏着人家的小弟，就不能叫闭包。

所以枚举每个字符 `c`，以 `first[c]` 为左端点，尝试扩出一个“最小合法闭包”。

初始范围 `left=first[c], right=last[c]`，从左往右扫范围内的每个字符 `ch`：

- 如果`last[ch] > right`：右边还有 `ch` 帮的小弟没进来——**扩**！ 右边界拉到 `last[ch]`，新地盘进来后 `right` 更新，继续查，连锁反应不能漏。
- 如果`first[ch] < left`：左边还有 `ch` 帮的小弟没罩住——**寄**！这个闭包永远收不拢，左端点直接淘汰。

```python
intervals = []
for c in first:
    left, right = first[c], last[c]
    j = left + 1
    ok = True
    while j <= right:
        ch = s[j]
        if first[ch] < left:
            ok = False
            break
        if last[ch] > right:
            right = last[ch]
        j += 1
    if ok:
        intervals.append((left, right))
```

一轮下来，每个能自洽的左端点都会滚出一个最小闭包；滚不出来的，直接淘汰。活下来的闭包，就是候选子串。

------

#### 第三步：贪心收割——谁先结束就选谁

候选子串到手，现在要从这堆区间里挑出最多的互不重叠的子串。

经典区间调度，直接上贪心：按右端点排序，谁先结束选谁，保证**数量最多**。

但题目里还有个抠门条件：数量一样多时，**总长度要最短**。

还能贪心吗？

一般的区间调度，按右端点贪心只管数量，不管总长。区间半重叠的时候最容易翻车——贪心选了个早结束但更长的区间，把后面更短的小区间挤掉了，数量没变，总长却涨了一截。

但幸运的是——或者说，出题人手下留情了——这里的候选闭包不是普通区间，是**套娃体质**：要么完全不相交，要么一个包住另一个，绝不半重叠。

为什么？因为每个候选闭包都是从某个字符的 `first` 出发，把所有牵连帮派全滚进来才收手。既然"碰了就得全收"，那闭包之间要么各玩各的，要么小的被大的整个吞掉。

套娃结构下，大闭包一定包含小闭包，所以小闭包更短、右端点也更靠左。贪心按右端点选，**天然先收割最内层、最短的那个**。

换句话说，"最早结束"和"最短"在套娃结构里是同一件事。贪心一步到位，数量和长度一起拿下。

```python
intervals.sort(key=lambda x: x[1])

res = []
end = -1
for left, right in intervals:
    if left > end:
        res.append(s[left:right + 1])
        end = right
return res
```

------

#### 复盘

三步走，全程线性，效率拉满：

1. **摸清堂口** first/last：扫一条街，O(n)。
2. **滚出闭包**：最多 26 个帮派，每个最多扫一遍，总共 O(26n) = O(n)。
3. **贪心收割**：最多 26 个候选子串，排序 O(26 log 26) = O(1)。

总时间 O(n)，空间 O(n)。一趟街走完，收工。

这题的灵魂就一句话：**套娃结构让"最早结束 = 最短"**，贪心一步到位，数量和长度双杀。

属于题目替你砍了最难的部分，你只管贪心收人就行。
