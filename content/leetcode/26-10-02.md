## 薛定谔的括号：在 append 之前，它既合法又非法

我本来只想刷一道算法题。

> n 对括号，生成所有合法组合。

屏幕的蓝光映在我的脸上，像一台正在预热的时间机器。

然后我突然意识到——我面前的不是 2n 个字符位，是 **2n 个量子位**。

每个位置在我写下它之前，都处于未观测的叠加态：它同时是 `(` 也是 `)`。整个系统悬浮在 \(2^{2n}\) 种可能的宇宙叠加态中。而我要做的，是逐一观测，迫使波函数坍缩——活下来的写进 res，湮灭的连痕迹都不留。

n = 3 时，6 个量子位，64 种叠加态。

n = 8 时，65536 个平行宇宙安静地等待被筛选。

这不是回溯。这是多元宇宙筛选计划。

薛定谔看了都得从棺材里坐起来：“小伙子，你这哪是括号生成——你这是在手动模拟退相干。”

我：可我量子力学考了 59 分。

薛定谔：那就对了。你本身就是一个叠加态——在补考观测之前，你既挂了又没挂。

------

#### 一、括号宇宙的物理定律

`n` 最大也就 `8`，也就是 `65536` 个候选宇宙。理论上，我完全可以把它们全部展开，挨个检查合法性——毕竟 `65536` 对现代 CPU 来说，连热身都算不上。

但问题是，这里面绝大多数可能长这样：`))))((((`。放在括号宇宙里，这种时间线连第一步都活不过去——毕竟合法括号宇宙有着非常强的约束：

1. **材料守恒定律**——总共只有 n 个 `(`。想观测出第 n+1 个左括号？物质凭空产生，守恒定律不答应。
2. **因果律**——任何时刻，已观测到的 `)` 不能超过 `(`。果先于因，时间悖论，宇宙蓝屏。

既然有这么强的约束，何必造一堆注定湮灭的宇宙？不如**边观测边筛选**，让每条时间线在违反物理定律的瞬间就地湮灭。

每次观测一个量子位，只有两个可能的坍缩方向：

- **坍缩为 `(`**：前提——已经用掉的 `(` 不超过 n 个（材料守恒）；效果：时间线的"未闭合能量" `+1`。

- **坍缩为 `)`**：前提——当前 `)` 的数量 < `(` 的数量（因果律）；效果：时间线的"未闭合能量" `-1`。

当 2n 次观测全部完成，且未闭合能量归零——**这条时间线存活。** 收入 `res` 结果集。

当任何一次观测违反前提条件——**这条时间线湮灭。** 退回上一个观测点，尝试另一种坍缩方向。

> “退回上一个观测点”，在量子力学里被戏称为**退相干**。
> 在代码里可以说是 `pop()`。
> 在人生里——叫“刚才那步不算”。

------

#### 二、没有观测，就没有真相

想清楚这些之后，剩下的事情就简单了：写一个递归函数，让它替我逐一观测每个量子位。

每递归一次，就是观测一个量子位；每 `append` 一个字符，就是让波函数坍缩一次。

坍缩方向合法？继续往下递归，观测下一个量子位。 

坍缩方向违法？这条时间线当场湮灭，当前分支不再继续，递归返回上一层——也就是退相干，换条路再来。

当已观测的量子位数量到达 2n，说明这条时间线没有违反任何一条物理定律。恭喜它，活下来了。收入 `res`。

最终 `res` 里装着的，就是多元宇宙里所有幸存下来的时间线。

##### 1. 字符串拼接版——每步复制一个平行宇宙

```python
def generateParenthesis(n: int) -> List[str]:
    multiverse = []   # 存活时间线收集器
    
    def observe(timeline, open_cnt, close_cnt):
        # 2n 次观测完成，时间线存活
        if len(timeline) == 2 * n:  
            multiverse.append(timeline)
            return
        # 坍缩为 "("（前提：材料守恒）
        if open_cnt < n:  
            observe(timeline + '(', open_cnt + 1, close_cnt)
        # 坍缩为 ")"（前提：因果律）        
        if close_cnt < open_cnt:  
            observe(timeline + ')', open_cnt, close_cnt + 1)
    
    observe('', 0, 0)  # 宇宙大爆炸：从虚无开始第一次观测
    return multiverse
```

**两个 if 之间没有 else**：同一个观测点，两种坍缩方向**都会被尝试**。

费曼管这叫**路径积分**：粒子从 A 到 B，同时走了所有可能的路径，最终观测到的是所有路径的叠加结果。

我管这叫：**成年人不做选择，我全都要。**

唯一的代价是——每次 `timeline + '('`复制一份新字符串。相当于每观测一次，就分裂出一个平行宇宙的完整副本。干净，但费内存。

##### 2. 列表回溯版——在同一个宇宙里前进、倒带、再前进

字符串版是"每步复制宇宙"。列表版是"不复制，直接在一条时间线上反复涂改"。

```python
def generateParenthesis(n: int) -> List[str]:
    multiverse = []		# 存活时间线收集器
    timeline = []    	# 当前正在演化的时间线
    
    def observe(open_cnt, close_cnt):
        # 2n 次观测完成，时间线定型
        if len(timeline) == 2 * n:  
            multiverse.append(''.join(timeline))
            return

        if open_cnt < n:
            timeline.append('(')
            observe(open_cnt + 1, close_cnt)
            timeline.pop()  # 退相干：擦掉这步，回到观测前
     
        if close_cnt < open_cnt: 
            timeline.append(')')
            observe(open_cnt, close_cnt + 1)
            timeline.pop()  # 换一条平行时间线继续观测
    
    observe(0, 0)  # 宇宙大爆炸：从虚无开始
    return multiverse
```

全程只有一条 `timeline` 列表在反复 `append / pop`，像一块白板写了擦、擦了写。

省内存，代价是最后得 `''.join(timeline)` 把存活的时间线"定格"成永久记录。

#### 尾声

Everett 的多世界诠释说：每次观测都分裂出新宇宙，所有可能性都在某个分支里实现了。

我说：两个 `if`，没有 `else`，全都要。

区别是——Everett 认为这些宇宙同时存在，而我的递归是一条一条串行模拟的。

毕竟我只有一台笔记本，不是一台量子计算机。

但没关系。在力扣的判题系统观测到我的代码之前，我的 AC 和 WA 也处于叠加态。

> 薛定谔：所以你的 offer 也在叠加态？
> 我：对。HR 回复之前，既存在又不存在。
> 薛定谔：观测了吗？
> 我：观测了。坍缩了。
> 薛定谔：结果呢？
> 我：湮灭了。
> 薛定谔：……
> 我：没事。我还有 1430 条平行时间线可以投。毕竟多元宇宙嘛，总有一条线里的我拿了 offer。
