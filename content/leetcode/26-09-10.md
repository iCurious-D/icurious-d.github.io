## 我在树下做了个梦，梦见自己被卷成了二叉树节点

------

产品经理第 17 次改需求的时候，我正在改第 16 版的接口。

我是一个后端。这个职业的核心竞争力，就是永远比产品经理慢一版。

钉钉弹出来，我甚至不用点开就知道——又是“很简单”。

> “这个统计功能很简单，就在树上数一下符合条件的节点数，明天早上老板要看，辛苦啦～”

凌晨 2:47。我拿起咖啡又放下——心脏已经开始打碟，再灌一杯就是 ICU 直通车。

我关掉 IDE，决定下楼透口气。

凌晨的写字楼大堂空得像被格式化过。保安在打瞌睡，旋转门转得比我的职业发展还慢。我走到楼下那排梧桐树旁边，挑了棵最粗的靠着，打算眯五分钟。

然后，我睡着了。

------

#### 入梦：一棵树把我收了

再睁眼的时候，我下意识去摸手机，想看看钉钉有没有炸。

结果摸到的不是手机，是一根草——比我胳膊还粗，叶片上的露水像一颗悬在半空的玻璃球。

我愣了两秒，坐起来，发现脚边的沙子像砖块，远处的草坪像原始森林，一只蚂蚁从旁边跑过，体型跟我差不多。

这什么魔幻剧情？！我变小了？

我恍惚地往后一靠——刚才那棵梧桐树的树干，现在就像一面墙，树皮纹路深得能攀岩。

然后我抬头，看到了更离谱的。

这棵树是**倒过来长的**——根扎天上，枝叶铺地，像有人一键 `Ctrl+Z` 到了盘古开天之前。树上传来一个声音，慢悠悠的，像从很深很深的调用栈底部冒上来：

> “欢迎来到**倒立二叉树宇宙**。我是根节点，你可以叫我 `root`。”
> “你的工位已经分配好了，就在我下面那层。”

我循声找过去，倒垂的树干上坐着一个老头，两条腿悬在半空晃着——白胡子长得像没清理过的依赖链，老花镜后面的眼睛精得像个 debug 了三十年的老手。

“等等——” 我试图冷静下来：“我不是节点，我是后端工程师。”

老头冷笑了一声：

> “后端？后端的世界，谁不是节点？”
> “你的直属领导是你的父节点，你的直属下属是你的子节点——一个左膀一个右臂。”
> “没有下属的就是叶子节点——底层打工人，背锅终点站。”
> “没有父节点的就是根节点——CEO，所有锅的最终归宿。”
> “你，早就活在一棵二叉树里了。”

我沉默了。

------

#### 规则：节点的价值对齐

老头扔给我一份《二叉树生存手册》，让我翻到第 2265 条：

> 每个节点计算自己子树的平均值（**向下取整**）。
> 如果你的值恰好等于这个平均值，你就是"天选平均打工人"。
> 如果不等——比平均高，卷王；比平均低，混子。统统要被喊去谈话。
> 谈话内容通常是：“你对自己的定位是不是有点偏差？”

我心想，这不就是绩效考核？

老头瞅了我一眼：“什么考核，这叫‘节点价值对齐’。”

然后他指了指下面：“别愣了，你的左膀右臂已经在算了。”

我低头一看——脚底下还真挂着两个小节点，一左一右。左边那个节点工号 `8`——正在掰手指：

> "我子树有 `8, 0, 1`，总和 9，3 个节点——`(9， 3)`。平均 `9 // 3 = 3`。我是 8，不等于 3，卷王。"

他叹了口气，像极了上个月绩效 A 被老板偷偷喊过去的同事——太强了，强到团队平均配不上。

旁边右边那个工号 `5`——淡定得多：

> "我子树有 `5, 6`，总和 11，2 个节点——`(11， 2)`。平均 `11 // 2 = 5`。我是 5，等于 5，天选。"

我注意到一个细节：`11 // 2 = 5`，不是 5.5。**向下取整**。小数点后面直接砍。

我：“所以绩效 3.9 的打工人，在公司眼里只有 3？”

老头：“只舍不入，你以为年终奖的 0.9 是白来的？”

------

#### 递归：层层甩锅的艺术

我还想吐槽，老头敲了敲树皮：“别光顾着笑，你那俩下属把数据包举半天了。”

我低头一看——左边工号 `8` 手里攥着 `(9, 3)`，右边工号 `5` 手里攥着 `(11, 2)`，俩人仰着头看我，表情像极了周五下午等我 code review 的实习生。

“**后序遍历**的规矩，”老头说，“左右先算完，结果往上一交，就轮到你了。接住他俩的包，加上自己，算平均，判断，打包，往上传——这活你熟。”

他顿了顿，又补了一刀：“翻译成人话就是：先被左边下属折磨，再被右边下属折磨，最后自己折磨自己。”

我怀疑这老头是不是偷看了我的钉钉日志。

但他说得没错——我的左膀 `8` 干的是这个，右臂 `5` 干的也是这个，现在轮到我了，还是这个。整个团队做的都是同一件事，只不过每个人管的范围不一样。

这不就是递归吗？定义 `dfs(node)`，给它一个节点，返回一个数据包 `(子树总和, 子树节点数)`。左子树调一次，右子树调一次，等包到齐，加上自己，算完再往上传。

一层一层往上甩，谁也别想跑。

“就像层层甩锅——”我喃喃自语，“空节点没锅可背，返回 `(0, 0)`。其它节点，左右两口锅全接住。”

老头点点头，但又很快纠正道："我们二叉树的世界，可没有锅，只有数据包。”

```python
def averageOfSubtree(root: Optional[TreeNode]) -> int:
    ans = 0

    def dfs(node: TreeNode) -> (int, int):
        nonlocal ans
        if not node:
            return 0, 0
        left_sum, left_count = dfs(node.left)
        right_sum, right_count = dfs(node.right)
        total_sum = left_sum + right_sum + node.val
        total_count = left_count + right_count + 1
        avg = total_sum // total_count
        if node.val == avg:
            ans += 1
        return total_sum, total_count

    dfs(root)
    return ans
```

时间复杂度 O(n)，每个节点只被访问一次，每个节点只汇报一次。
空间复杂度 O(h)，`h` 是树高。递归深度就是树的高度——树有多深，锅就甩得有多远。

------

#### 梦醒：风没接我的话

就在我准备问老头“那我到底算不算天选平均打工人”的时候，一阵风吹过。

我醒了。

我还是那棵梧桐树下，还是凌晨三点。保安的呼噜声从大堂里传出来，旋转门停在了一个尴尬的角度。

我摸了摸嘴角——没流口水，但脸上有树皮的印子。大概是睡着的时候拿脸蹭的。

起身之前，我好像听到风中隐约传来一句：

> “记住，二叉树的问题，大部分都能用递归解决。”

我在心里默默接了一句：那产品经理的问题呢？

风没回答。大概是超时了。
