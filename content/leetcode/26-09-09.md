## 星星还没数，力扣先涨了十个数量级

昨天(3870)的 `n` 上限还是 `10^5`，今天(3871)就膨胀到了 `10^15`。

好在你昨天多想了一步，段位线解法今天原装上场：

```python
def countCommas(n: int) -> int:
    ans = 0
    line = 1000
    while line <= n:
        ans += n - line + 1
        line *= 1000
    return ans
```

`10^15` 也就五条段位线，循环五次就搞定。

你抬头望天：“那个啊，那是限定皮肤，今天过期了。”
