## 项目概述

电商客服助手是一个基于 Rasa 开源框架构建的智能对话系统，面向电商场景的客户服务需求。系统能够理解用户的自然语言输入，自动识别意图（如查询订单、申请退款、咨询物流等），提取关键实体（订单号、商品名称等），并通过预设的对话流程完成多轮交互，减少人工客服的工作量。

## 技术架构

```
用户输入
  ↓
NLU 管道（意图识别 + 实体提取）
  ↓
对话状态追踪（Tracker）
  ↓
对话策略（Policy）决策
  ↓
动作执行（Action）
  ↓
回复生成
```

**核心技术栈**：Rasa + Python + NLU Pipeline

## 核心功能

### 1. 意图识别（Intent Classification）
通过 Rasa NLU 管道对用户输入进行意图分类，覆盖电商场景的常见意图：查询订单状态、申请退换货、咨询商品信息、投诉反馈等。支持自定义训练数据扩充，持续提升识别准确率。

### 2. 实体提取（Entity Extraction）
从用户输入中自动提取关键业务实体，如订单编号、商品名称、日期范围等。结合正则表达式和模型预测，确保实体识别的准确性和鲁棒性。

### 3. 多轮对话管理
基于 Rasa 的 Stories 和 Rules 机制，编排复杂的对话流程。例如退款流程：确认订单 → 验证退款条件 → 收集退款原因 → 提交退款申请，每一步都有对应的对话节点和异常处理。

### 4. 槽位管理（Slot Filling）
通过 Slot 机制维护对话过程中的关键状态信息（如当前操作的订单号、用户选择的退款方式等），确保跨轮次的信息连贯性。

### 5. 自定义动作（Custom Actions）
对接后端业务系统，实现订单查询、物流跟踪、退款提交等实际操作。通过 Rasa SDK 编写 Python 动作函数，连接数据库和外部 API。

## 技术亮点

- **NLU 管道定制**：根据电商场景定制 NLU 组件，包括分词、特征提取、意图分类器的选型与调优
- **对话流程编排**：使用 Stories（训练数据驱动的对话路径）和 Rules（强制执行的对话规则）结合的方式，兼顾灵活性和确定性
- **兜底策略（Fallback）**：当 NLU 置信度低于阈值或对话流程无法匹配时，自动转接人工客服，保障用户体验
- **意图冲突处理**：针对用户在对话中途切换意图的场景（如查订单时突然问退款），设计中断与恢复机制

## 项目成果

- 实现了电商场景下常见客服问题的自动化处理
- 深入理解了传统 NLU 对话系统的架构设计，包括意图识别、实体提取、对话状态管理等核心模块
- 对比了基于规则的对话系统（Rasa）与基于 LLM 的对话系统在可控性、成本和效果上的差异，为后续 RAG/Agent 方向的技术选型提供了参考
