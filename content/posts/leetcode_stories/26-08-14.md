## 生存游戏续作：2958 换皮实锤，但真香

------

#### 开箱

我，一个刚在前天通关《孤岛生存：K之试炼》的老玩家，正躺在沙滩椅上等下一波更新。

系统弹窗来了：

> **“《孤岛生存2：字母危机》现已上线！全新冒险！全新物资！全新……”**

我眼睛一亮，秒进。

加载完成——还是那片沙滩，还是那条破传送带。 脚边甚至躺着我前天扔掉的那个椰子壳，连位置都没挪过。

系统提示音继续，但语气明显有点虚：

> **“全新物资！全新挑战！全新……算了不装了，就是 k 锁死成 2，物资换成字母，你爱玩不玩。”**

我：“……”

行，来都来了，捡呗。

------

#### 换皮实锤

**画面**：没变。沙子一样烫脚，传送带一样嘎吱响。

**物资**：从椰子木板铁片，变成了 `'a'` `'b'` `'c'`。我盯着一个发光字母块看了半天，策划连图标都懒得画了？

**玩法**：没变。右手捡、左手扔，滑动窗口老套路。

**唯一的变化**：堆叠上限 k 从“可变”变成了**固定 2**。同种字母第三个进包就炸。

我差点想卸载。

这不就是 2958 的特例吗？模板一模一样，就 `k` 写死成 2，这不是续作，这是前天的 **k=2 特供复刻版**。

但作为一个刷题老油条，骂归骂，手已经先一步打开了编辑器。我盯着那些发光字母块——小写英文字母？满打满算 26 种，字符集被锁死了。那还用什么哈希表？直接开个 26 格数组，一个字母一个坑，来了 +1，多了扔最早的。

```python
def maxLength(s: str) -> int:
    cnt = [0] * 26          # 26个位子，a到z专属
    ans = left = 0
    
    for right, ch in enumerate(s):
        idx = ord(ch) - ord('a')
        cnt[idx] += 1          # 右手捡
        
        while cnt[idx] > 2:    # 第三个同款？左手扔
            oldest_idx = ord(s[left]) - ord('a')
            cnt[oldest_idx] -= 1
            left += 1          
        
        ans = max(ans, right - left + 1)  # 记最长合法窗口
    
    return ans
```

不过话说回来，计数器从字典换成固定 26 格数组，快是快了那么一丢丢，但数据量才 100，这点优化约等于给自行车装涡轮——心理安慰大于实际效果，纯属强迫症福音。

------

#### 真香

骂归骂，手倒是很诚实，一路捡一路扔，直到传送带彻底停下。

沙滩上散落着被我扔出去的字母块，歪歪扭扭拼成了一行字：**Accepted**。

系统提示音再次响起，这次居然带了点笑意：

> **“恭喜，滑动窗口熟练度 +1。”**

我笑了。

行吧，说它是续作，不如说是 2958 的官方教学关，还自带“字符集固定”的新手保护。但简单模式也有简单模式的爽——不用管什么椰子木板铁片，闭眼就是 26 个字母，左手右手各司其职，跑一遍就过。真香。
