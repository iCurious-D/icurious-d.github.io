## 二维人吵架，一维人解题，三维人写代码

------

我第一次见到二维居民的时候，他们正在吵架。

事情是这样的：矩形 A 和矩形 B 站在坐标系里，面红耳赤。A 说“你碰到我了”，B 说“放屁，我离你八丈远”。

作为一个三维人，我看得清清楚楚：A 的领地是 `[0,0]` 到 `[2,2]`，B 的领地是 `[1,1]` 到 `[3,3]`，重叠明晃晃地摆在那——可它们自己似乎完全不知道。

我忍不住插嘴：“你俩重不重叠，自己看不出来？”

A 和 B 同时沉默了。

原来，二维居民能感知自己的长和宽，却没法同时感知两个矩形的相对位置——就像你能看见自己的脸，却看不见自己的后脑勺一样。维度给了你广度，也给了你盲区。

这时，旁边一直没说话的矩形 C 叹了口气，指了指脚下那条细细的 x 轴：“你们去找一维长老吧。它虽然只活在一条数轴上，但看问题比咱们清楚。”

“一条线能懂什么矩形？” A 不屑。

C 说：“它懂影子。”

A 和 B 对视一眼，决定试试。反正站着也是吵架，不如下去溜达一圈。

------

#### 一、拍扁成影子

它们把自己往 x 轴上一投影——巨大的二维身躯瞬间塌缩成一段线段。A 变成了 `[0, 2]`，B 变成了 `[1, 3]`。

那种感觉很难形容，就像从一个人变成了一道影子：少了宽度，少了高度，整个世界只剩左和右。但奇怪的是，你反而看清了一些在二维世界里永远看不清的东西。

一维长老开口了，声音像从数轴深处传来：“你们在二维世界争论'重不重叠'，争了几百年也没结果。知道为什么吗？”

“为什么？”

“因为你们试图在产生问题的维度里解决问题。”

A 觉得这话像极了它朋友圈里转发的鸡汤，但不得不承认——有点道理。

------

#### 二、起点取大，终点取小

一维长老说：“规矩很简单。你们二维人觉得复杂，是因为你们总想同时盯住两个方向。我只有一条数轴，一次只看一个方向。”

“先把自己拍扁成影子，投到 x 轴上，看 x 方向有没有交集；再投到 y 轴上，看 y 方向有没有交集。**两个方向都有交集，你们就重叠。一个方向没有，就不重叠。**”

A 将信将疑：“就这么……简单？”

长老没理它，直接在数轴上画了两段影子：“ x 轴上，你的影子是 `[0, 2]`，B 的影子是 `[1, 3]`。”

“两段影子有没有交集，就看它们谁先来、谁先走。**起点取大，终点取小。** 如果得到的起点小于终点，说明中间就有真正的重叠。”

A 琢磨了一下：“起点取大……就是 `max(0, 1) = 1`。终点取小……就是 `min(2, 3) = 2`。”

“对。`1 < 2`，所以交集就是 `[1, 2]`。”长老顿了顿，“你自己低头看看。”

A 低头一看——果然，它和 B 在 x 方向上共享了 `[1, 2]` 这段影子。

“y 方向同理，”长老说，“你的 y 影子 `[0, 2]`，它的 y 影子 `[1, 3]`。`max(0,1)=1`，`min(2,3)=2`，`1 < 2`——y 方向也有交集。”

“x 有，y 也有。”一维长老一拍数轴，“结论：**你们重叠。**”

------

#### 三、贴边不算

B 突然开口说道：“那要是我们刚好贴着呢？”

它把自己往右挪了一个单位，变成 `[2,1]` 到 `[4,3]`。x 方向上，它的左边界刚好踩在 A 的右边界上——两段影子在 `x = 2` 处碰头，像两节车厢挂钩，严丝合缝。

长老看了一眼：“x 方向：起点取大，`max(0, 2) = 2`；终点取小，`min(2, 4) = 2`。`2 < 2`？**不成立。**”

B 愣了：“可我们明明贴在一起啊。”

“贴在一起，但中间没有厚度。”长老说，“交集得是一段有长度的区间，不能是一个点。`[2, 2]` 是什么？是一个点。面积为零。你们二维世界有条规矩——**只在角或边接触，不算重叠。**”

B 还不死心：“可我们 y 方向重叠了啊？”

“y 方向确实重叠了，”长老说，“你的 y 影子 `[1, 3]`，A 的 y 影子 `[0, 2]`，`max(1,0)=1`，`min(3,2)=2`，`1 < 2`，有交集。但没用。**一个方向不重叠，整体就不重叠。** 就像两个人时间对得上，但地点永远错开，那还是见不了面。”

B 终于服了。

------

#### 四、三维人的笔记

“三维来的那位，”一维长老看了我一眼：“你站半天了，是不是该把这事儿记下来？我这数轴可没地方存笔记。”

我这才想起来，自己一直站在旁边看戏，差点忘了正事。赶紧掏出手机。

长老眯起眼：“那是什么？一块会发光的石板？”

“三维世界的石板，”我说，“能存东西，还能运行代码。”

“代码？”长老皱眉，“你们三维人的玩意可真多。”

```python
def isRectangleOverlap(rec1: List[int], rec2: List[int]) -> bool:
    return max(rec1[0], rec2[0]) < min(rec1[2], rec2[2]) and \
           max(rec1[1], rec2[1]) < min(rec1[3], rec2[3])
```

`rec1[0]`、`rec2[0]` 是两个左边界，`max` 取大的——影子的起点。
`rec1[2]`、`rec2[2]` 是两个右边界，`min` 取小的——影子的终点。
x 方向判完，y 方向照搬：`rec1[1]`、`rec2[1]` 是下边界，`rec1[3]`、`rec2[3]` 是上边界。

O(1) 时间，O(1) 空间。四个坐标取两次 max、两次 min，完事。

------

#### 尾声

我对一维长老说：“你只有一个维度，却看得如此清楚。”

长老说：“不是我看清楚，是你们维度太多，把自己绕进去了。你们总以为多一个维度就多一层智慧——但有时候，多一个维度只是多一个吵架的方向。”

我想了想，问：“那你们一维世界，有没有什么问题是解决不了的？”

长老沉默了一会儿。数轴上的风很轻，吹得它的影子微微晃动。

> 有。我们永远不知道自己是胖是瘦，因为我们连'宽'这个概念都没有。
> 降维能帮我们解决高维的问题，但也会丢掉一些东西。这叫**降维代价**。

它顿了顿，又补了一句：

> 降维不一定是毁灭，它也可能只是解题。但解题的人，要记得自己丢过什么。

我点点头，转身回到了我的三维世界。

风从四面八方吹来。
