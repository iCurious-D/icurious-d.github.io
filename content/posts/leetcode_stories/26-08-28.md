## 半个回文，一场贪心

给你两个字符串 `s` 和 `target`，要求把 `s` 的字母重新排队，排出来的串得同时满足三个变态条件：

> ① 得是回文；
> ② 字典序严格大于 `target`；
> ③ 在满足前两条的合格者里，挑字典序最小的那个。

排不出来？出门右转领一个空字符串 `""`。

别被它那“困难”的标签唬住。这题难度全在**概念套娃**，属于典型的“脑子会了手就会了”系列。

拆开就三步，比把大象放进冰箱还少一步：**验货 → 砍半 → 对线**。

------

#### 第一步：验货——`s` 能不能拼回文？

回文这玩意儿，天生有强迫症：字母必须成双成对，最多允许一个“孤勇者”站中间当 C 位。

> `"aab"`，两个 `a` 手拉手，`b` 落单，站中间当吉祥物，`"aba"` 完美！
> `"abc"`：好家伙，三个单身狗，谁站中间另外俩都得打起来，直接 GG，返回 `""`。

所以第一件事：掏出你的小本本统计 `s` 里每个字母出现的次数。

**如果出现奇数次的字母超过 1 个，直接返回 `""`**。否则，那个落单的字母（如果有），先记作 `mid`，它就是未来回文里站中间的“天选之子”。

------

#### 第二步：砍半——右半是纯纯工具人，别给它加戏

回文长这样：`回文 = 左半 + 中间(可能没有) + 左半的倒序`

比如，`"baab"` 就是 `"ba"` + `"ab"`。仔细看**右边那块，它就是个镜像**，左半写啥它反着抄啥，纯纯工具人。

工作量直接砍半——**你只需要搞定左半就够了，右半是买一送一的赠品**。

> 用 `s` 字母一半的库存（每个字母拿一半，落单的留给中间），拼一个**字典序最小的左半**，使得整个回文（左半 + mid + 左半倒序）刚好比 `target` 大那么一丢丢。

------

#### 第三步：和 target 对线——左半怎么卷，才能刚好压线？

砍半后，你手里就剩一堆**"半串库存"**，记作 `rem`。

比如 `s = "aabbcc"`，那 `rem = {a:1, b:1, c:1}`——每个字母只拿一半，童叟无欺。

目标很明确：拼一个左半串 `R`，要同时满足：

- 字母全从 `rem` 里出，不能赊账；
- 整个回文 `R + mid + R[::-1]` 必须严格大于 `target`；
- 在所有能赢的 `R` 里，字典序最小。

怎么对线？贪心三招，由躺到卷。

**第一招：躺平流——先试试最低配**

能躺则躺，先造个**最"低配"的左半**：`lowest = "".join(sorted(rem.elements()))`。

这家伙是所有能拼出的左半里字典序最小的。要是它直接就比 `target` 的左半（`target[:half]`）大——直接躺赢：字典序最小 + 大于 target，俩条件一手抓，直接返回 `lowest + mid + lowest[::-1]`，收工。

躺赢确实香。但现实是，`target` 多半不给你这个面子。

没躺成？别急，还有招。

**第二招：复制流——照抄 target 的左半，然后比中间和右半**

最低配打不过，那说明左半不得不“卷”一下。

先来个最贪心的思路：**左半干脆照抄 target 的左半**，一模一样，把输赢拖到中间和右半去拼。

但能不能抄，还得先瞅眼库存情况：你手里这个“半串库存” `rem`，能不能对上`target` 左半的字符构成？

对得上，才有资格抄。一旦抄了，前一半就被 `target` 钉死，右半又是左半的倒序、同样固定——输赢全看中间和右半了：

- **奇数长度**：`mid` 更大 → 赢；`mid` 相等但左半倒序 > `target` 右半 → 赢。
- **偶数长度**：直接拿左半倒序跟 `target` 右半比，谁大谁赢。

打平这条路最多只有一个答案（左半钉死，整串固定），赢了直接交卷；输了也别气馁，还有最后一招。

**最后一招：卷王微操——从右往左，精准卡点**

前两招都哑火，说明左半必须严格大于 target 的左半。

现在问题变成：

> 找一个字典序最小、但又严格大于 `t` 的左半串 `R`。

这不就是老朋友"下一个排列"穿了件马甲嘛。口诀就一句：**从右往左，找第一个能抬高的位置**。

为什么从右往左？因为字典序是从左往右比的——前面尽量保持原样，改得越靠右，对整体字典序的影响就越小。所以第一次成功，就是最优解。

具体三个动作：

1. 验库存：先确认库存够不够原样凑出前缀 `target[:i]`。不够？这个位置直接 pass，往左挪。
2. 抬一档：库存够，就在当前位置 `i` 放一个**比 `target[i]` 大、库存里有、还最小的字母** `ch`。
3. 垫底排好：`i` 之前原样照抄，拼上 `ch`，`i` 之后把剩余库存升序铺好——左半串 `R` 出炉，既压过 `target` 左半，又是字典序最小。搞定，收工。

从右往左扫，第一个命中的位置 `i` 就是答案；一路扫到最左都没抬起来，那是真拼不出来，返回 ""。

------

思路捋清楚，代码纯翻译：

```python
def lexPalindromicPermutation(s: str, target: str) -> str:
    n = len(s)
    cnt = Counter(s)

    # 第一步：验货。
    odd = [ch for ch in cnt if cnt[ch] % 2 == 1]
    if len(odd) > 1:
        return ""
    mid = odd[0] if odd else ""

    # 第二步：砍半
    half = n // 2
    rem = Counter({ch: c // 2 for ch, c in cnt.items()})
    t = target[:half]

    # 第三步：对线
    
    # 1. 最低配
    lowest = "".join(sorted(rem.elements()))
    if lowest > t:
        return lowest + mid + lowest[::-1]

    # 2. 左半照抄，比中间和右半
    if Counter(t) == rem:
        if n % 2:
            if mid > target[half] or (mid == target[half] and t[::-1] > target[half + 1:]):
                return t + mid + t[::-1]
        elif t[::-1] > target[half:]:
            return t + t[::-1]

    # 3. 前两条路都走不通：从右往左开始对线
    for i in range(half - 1, -1, -1):
        needed = Counter(t[:i])
        if any(needed[ch] > rem[ch] for ch in needed):
            continue
        for code in range(ord(t[i]) + 1, ord('z') + 1):
            ch = chr(code)
            if rem[ch] > needed[ch]:
                rest = rem - needed
                rest[ch] -= 1
                R = t[:i] + ch + "".join(sorted(rest.elements()))
                return R + mid + R[::-1]
            
    return ""
```

------

#### 尾声：

1. 回文问题先砍半：左半是战场，右半直接倒带。
2. 想最小且大于 `target`，先试最低配，能躺就躺，躺不平就抄，抄不了就从最右边精准卡点改一格。
3. 改得越靠右越好，改完后面用最小字典序填充。

最后补一句：`n ≤ 300`。 也就是说，你最多扫 150 个位置，就能赢。
