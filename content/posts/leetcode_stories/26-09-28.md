## 精神入栈，物理摸鱼

题目甩你一个“有效括号字符串” `s`，数字、`+ - * /`、括号，全员到齐。

阵容看着挺热闹，但数字和运算符都是纯纯背景板，负责营造数学氛围，真正的主角只有一个——括号。

------

#### 一：计数器模拟栈

括号的最大嵌套深度，翻译成人话：`(` 入栈，`)` 出栈，问栈最高堆到几层。

既然只关心层数，就不用真开一个列表。整数 `depth` 当计数器，遇到 `(` 就 +1，遇到 `)` 就 -1，顺手更新最大值。

```python
def maxDepth(s: str) -> int:
    max_depth = 0
    depth = 0
    for char in s:
        if char == '(':
            depth += 1
            max_depth = max(max_depth, depth)
        elif char == ')':
            depth -= 1
    return max_depth
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`。一个整数搞定，属于精神入栈，物理摸鱼。

------

#### 二：Pythonic 魔法

给每个字符定涨跌：`(` 是 `+1`，`)` 是 `-1`，其他字符横盘为 `0`。

`accumulate` 负责画 K 线，`max` 负责 K 线找顶——前缀和的历史最高点。

```python
from itertools import accumulate

def maxDepth(s: str) -> int:
    return max(accumulate(s, lambda d, c: d + (c == '(') - (c == ')'), initial=0))
```

`(c == '(') - (c == ')')` 一行把三种情况全包了：

- 如果 `c == '('`：`1 - 0 = 1`
- 如果 `c == ')'`：`0 - 1 = -1`
- 其他字符：`0 - 0 = 0`

`initial=0` 是安全垫：万一一个括号都没有，兜底返回 `0`。

时间复杂度 `O(n)`，额外空间 `O(1)`。`accumulate` 是惰性迭代器，边算边扔，不囤内存。

#### 彩蛋

最后送三条括号冷知识：

1. “parenthesis”来自希腊语，字面意思是“放在旁边的东西”。最早它真是个旁注，用来在文本边上插一嘴“哎，这里补充一下”。直到1544 年，圆括号 `()` 被数学家拉进公式，专门负责抢运算优先级——从旁注到 C 位，括号正式出道。18 世纪，圆括号、方括号、花括号组成“括号全家桶”，横扫数学界。
2. 计算机出现后，数学家的优雅套娃，成了程序员的噩梦。1955 年，Samelson 和 Bauer 研究公式翻译，就被嵌套括号卡住了：算到一半，里面还套着一层括号，半成品往哪塞？幸好当时机器里有个叫“Keller” 的部件——一个后进先出的临时仓库。两人一对视：“这玩意不就是为括号准备的吗？” 从此括号和栈成为经典 CP。后来两人把栈原理申请了专利，拿下德国计算机科学的第一项美国专利。

3. 最后，不能不提一嘴 Lisp 程序员。他们一辈子活在括号森林里。IDE 的“括号匹配高亮”对他们来说近乎行为艺术——打开文件的那一刻，整个屏幕闪闪发光。
