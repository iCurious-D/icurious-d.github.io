## **MC被三诅咒的末地石：余数才是本体**

#### **开局**

上次拆完塔，我以为这事翻篇了。

结果第二天半夜，Discord 又响了。Bob 的消息只有一行：

> “新图做好了。来。”

我点了传送邀请，眼前一黑，再亮起来时已经站在一个巨大的紫色基岩平台上。地上摆满了石子——不是普通圆石，是那种末地里发着幽光的末地石，每一块上面都刻着一个数字。

Bob 站在平台另一头。还是那副修长漆黑的末影人身板，紫色眼睛比上次亮了一个色号。脚边插着块新告示牌：

> **被三诅咒的末地石**
> 地上有 n 块末地石，每块刻着一个数字。
> 两人轮流取一个。
> 如果谁取完后，所有已取石子的价值总和能被 3 整除，谁就会被丢下平台。
> 如果所有石子都取完了，还没人被 3 整除，先手直接判负。末地不提供平局。
> 你先手。双方最优策略。
> 问：你 能不能活着出去？

我把告示牌读了两遍。好家伙，这不是 Nim，这是“要么你死，要么我赢，没有平局”。

“所以如果所有石子都安全取完，没触发总和对 3 取余为 0，我就算输？Bob 你当裁判又当运动员，这规则比末影龙还黑。”

Bob 的紫色眼睛闪了闪，亮度大概从 40% 升到 80%。

------

#### 第一刀：万物皆可 mod 3

我蹲下来翻石子。每块末地石上的数字都不同，但没过十秒，我就发现一个关键事实：**这游戏根本不在乎数字本身，只在乎数字除以 3 的余数**。

判断输赢只看总和能不能被 3 整除。假设当前总和 `S`，取走一块价值 `v` 的石子，新总和就是 `S+v`。而 `(S+v) mod 3 = (S mod 3 + v mod 3) mod 3`——所以石子上的数字再花哨，真正身份就一个：**它对 3 取余是多少**。

直接按余数把它们分成三堆：

- **0 号石**：取了等于没取，总和余数原地不动——就像末地里的附魔书，看着高级，实际上不改变战局。
- **1 号石**：总和余数 +1，简单直接。
- **2 号石**：总和余数 +2，(也可以理解为 -1)。

我掏出命令方块，飞快地统计数量：

```python
cnt = [0] * 3
for x in stones:
    cnt[x % 3] += 1
```

三行代码，所有石子扒掉了数字外衣，只剩余数裸奔。

Bob 在旁边看我统计石子，突然举起了牌子：

> “数据清洗。”

我：“……你什么时候学会的这词？”

他没理我，只是用修长的手指敲了敲地面，示意我继续。

行吧。接下来该分析怎么取不会死。其实只看两样东西：当前总和余数 S，和取的石子余数。我在基岩上画了张表：

| 当前总和 mod 3 | 取 0 号石   | 取 1 号石   | 取 2 号石   |
| -------------- | ----------- | ----------- | ----------- |
| S = 0          | 出局。      | 安全（S→1） | 安全（S→2） |
| S = 1          | 安全（S→1） | 安全（S→2） | 出局（S→0） |
| S = 2          | 安全（S→2） | 出局（S→0） | 安全（S→1） |

“好家伙，”我拍了拍手上的紫灰，“开局 S = 0，第一手就不能碰 0 号石。进本第一个技能还没放，先给自己套了个即死 debuff。”

我看向那堆 0 号石，越看越像末地里人畜无害但会炸你一脸的潜影贝。

> “所以下一刀聊它。”

------

#### 第二刀：0 号石是传球

0 号石（mod 3 == 0）的特殊在于——取它之后，总和余数不变。

看起来像是"安全牌"对吧？不改变战局，白捡一分。

但你仔细想——你取了一块 0 号石，总和余数不变，安全是安全，但**回合交给对手了**。对手也取一块 0 号石，又把回合还给你。等于两个人在互相"传球"，而 0 号石的数量决定了这场传球能打多久：

- **`cnt[0]` 是偶数**：成对抵消，**先后手关系不变**，等价于没有 0 号石。
- **`cnt[0]` 是奇数**：多出一块，相当于有一个人能"强制换先手"。这就好比有个战复技能——关键时刻能翻转先后手，直接改变命运。

“偶数个没用，奇数个才毒。” 我敲了敲地面，“先打简单的——**偶数个 0 号石，全部抵消。游戏简化成只看 1 号石和 2 号石**。”

------

#### 第三刀：偶数个 0——挑少的路走

Bob 瞬移过来，蹲在我对面，像只好奇的末影猫。

“开局 S = 0，我先手只能选 1 或 2。”我捡起一块 1 号石在手里转，“假设选 `1`。接下来，Bob 如果取  `2`，S 余数直接变 0，当场出局——所以 Bob 没得选，只能跟着取 `1`。我下一手取 1 也会归 0，只能换 `2`。”

等等，**第一手之后，每一步都是被迫的**！序列从先手落下那一刻就固定死了。

> 先手选 1： 我 1, Bob 1, 我 2, Bob 1, 我 2, Bob 1, ……
> 先手选 2： 我 2, Bob 2, 我 1, Bob 2, 我 1, Bob 2, ……

Bob 从头到尾只取同类，我从第二手开始只能取另一类。谁先把自己那条赛道跑完，谁就不得不用对方的石子，而取对方石子会触发总和余数归 0，然后输掉比赛。

所以，我只要 **选数量较少的那类作为自己的第一手**。这样 Bob 就会被迫进入数量少那类的赛道，先耗尽，先撞墙。

“妙啊，”我拍了拍手——但等等，有一种特殊情况：如果场上只有一种非零余数呢？

比如只有 1 号石，我取 1，Bob 取 1，我再取 1——第三次余数归 0，我输。哪怕不够三个就取完了，规则也判 Bob 胜（石子取完，先手直接输）。只有 2 号石同理。

**结论：偶数个 0 时，0 号石全部抵消，只要两种非零余数(`1`号石子和`2`号石子)都有，先手选少的那类就能赢；缺一种就必输。**

```python
# 0号石互相抵消，先手只要 1号石子 和 2号石子 都有就能活
if cnt[0] % 2 == 0:
    return cnt[1] > 0 and cnt[2] > 0
```

------

#### 第四刀：奇数个 0——Bob 多一个回合，先手需要数量碾压

`cnt[0]` 是奇数，多出一块 0 号石——Bob 就拿到了一张额外的‘跳过回合’卡。

这块多余的 0 号石能让 Bob 在我第一手之后不取非零石，而是取 0 号石，把下一次非零动作又**推回给我**。

也就是说，之前的序列会发生微妙的变化：设我第一手选的那类为 `r`，序列就是`我 r, Bob 取0跳过, 我 r, Bob s, 我 r, Bob s, ……`。前两个 r 都是我取的。Bob 用那块 0 号石跳了一个回合，让我连续消耗两个 r，他一个 r 都没花。

我瞄了一眼 Bob，他的眼睛亮得像末地烛，显然等这一刻很久了。

我深吸一口气，冷静分析。设我先手选的 `r` 数量有 `a`个；另一类 `s`的数量有 `b`个。先手前两次已经用掉两个 `r`，剩余情况：`r 剩余：a - 2; s 剩余：b`。之后 Bob 消耗 `s`，我消耗 `r`。我想赢，必须等 Bob 把 `s` 全部耗完的时候，手里**还剩至少一个 `r`**——这样 Bob 被迫取 `r`，总和余数归 0，Bob 输。

所以必赢条件：`a - 2 > b` ，即 ` a - b > 2`。

只要两类非零余数的**数量差大于 2**，我选数量更多的那类作为自己的 `r`，就能稳赢。反过来，如果差距不够大，Bob 就能用那块 0 号石把我拖死。

```python
# 0号石奇数个，多一个换先符，看1和2的数量差
return abs(cnt[1] - cnt[2]) > 2
```

------

#### 尾声

我把答案敲进基岩平台上那个新冒出来的命令方块——上次好歹是个工具箱，这次直接从地板里长出来，末地连个 UI 都不装了。

命令方块嗡地一震，屏幕亮起一行字：**先手 获胜。**

Bob 看着结果，紫色的眼睛闪了闪，亮度慢慢降到最低。我差点以为他要关灯离场。过了好一会儿，他举起一块牌子：

> "你知道这次和上次有什么共同点吗？"

"什么？"

> "上次，必败态是稀缺资源——越少的东西越决定一切。这次，0 号石看起来最没用，但它的奇偶性直接翻转了整个博弈的底层逻辑。"

他顿了顿，眼睛又亮起来，像两颗充能完毕的末影珍珠：

> "**最不起眼的东西，往往是最关键的。** 就像末地里的末影螨——个头最小，但没它就没有末影珍珠。"

我盯着他，憋了半天：“你一个末影人，不去写鸡汤可惜了。”

Bob 没理我，身体开始分解成紫色粒子，飘散在紫色基岩上。
