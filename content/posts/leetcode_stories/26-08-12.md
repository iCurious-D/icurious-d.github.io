## **生存游戏教会我的事：右手捡，左手扔**

我一睁眼，咸腥的海风灌进鼻腔。

头顶是毒辣的太阳，脚下是烫脚的沙滩。一条不知道谁架的、嘎吱作响的传送带，上面源源不断滑来各种物资——椰子、木板、铁片、药草、鱼干……品种丰富得像在逛拼多多的九块九包邮专区。

还没等我反应，耳边响起一个毫无感情的系统提示音：

> **"欢迎来到《孤岛生存》。"**
>
> 规则如下：
>
> 1. 您必须**按顺序连续拾取**传送带上的物资，不可跳过。
> 2. **同种物品在背包中的堆叠上限为 k**，超限则背包爆炸，游戏结束。
> 3. 如需丢弃，只能从**最早捡起的物品开始逐个丢弃**。
>
> 生存目标：挑战**不炸背包的最长连续拾取长度**。
>
> **"祝您好运。"**

我看了看传送带——一个椰子正从上面滚过来，我下意识伸手接住。

行，生存游戏，我熟。MC 硬核生存三百天，饥荒联机两百小时，论捡垃圾，我是专业的。

------

#### 开局：我全都要

系统弹出参数：k = 3。我扫了一眼传送带，物资正陆陆续续地滑过来：

> `[木板, 椰子, 铁片, 椰子, 木板, 椰子, 木板, 椰子]`，

"简单。"我双手开工，进入肌肉记忆模式。木板，+1。椰子，+1。铁片，+1。椰子，+1。木板，+1。椰子——

**等等。**

好像开局捡过一个椰子？我低头看向背包。椰子上方浮现一个红色数字：**4**。

系统提示音温柔得像哄小孩：“椰子堆叠数 4 > k = 3。背包爆炸。Game Over。”

轰。

眼前一黑。死因：手比脑子快。

------

#### 重生：双手分工

再睁眼，还是那片沙滩，还是那条破传送带。

我爬起来，拍了拍沙子。刚才死得不冤——无脑全捡，同一种东西堆超了就炸。这就好比你明知道木材堆叠上限是 99，看到第 100 根还是忍不住伸手，然后整个背包红了。说白了，**贪，是要付出代价的。**

我重新捋了捋规则。必须连续拾取，不能跳过——这意味着我能拿到的物资，永远是传送带上**一段连续的序列**。而这段序列要想不炸背包，每种物品的数量都不能超过 k。

也就是说，我要找的是一个**连续的、每种物品不超过 k 个的最长区间**。等等——连续区间、计数上限、最长……这套路我见过，**滑动窗口**本体啊？！

想活命，双手要分工：

- **右手（right）负责捡**：新物资照单全收，来一个捡一个，计数器 +1。
- **左手（left）负责扔**：一旦某样东西超了 k，左手就得动起来——从背包最底下往外掏，那个最早塞进去的倒霉蛋先滚蛋，一路扔到惹事的那位计数降回 k 为止。

扔的过程免不了殃及池鱼——比如心爱的椰子、刚捂热乎的电池、还没来得及用的绷带，该丢得丢。没办法，规则要求连续，扔最早的东西，是唯一活路。

每轮调整完，背包必定合法。记下当前背包大小，跟历史最高纪录比一比。然后右手继续捡下一个，循环往复，直到传送带走到头。

一句话总结：**右手只管捡，超了左手扔，扔到不炸接着走，顺手记个最高分。**

```python
def maxSubarrayLength(nums: List[int], k: int) -> int:
	cnt = {}
	ans = left = 0
    for right, item in enumerate(nums):
        # 右手拾取
        cnt[item] = cnt.get(item, 0) + 1
        
        # 某物品超限，左手疯狂丢最早的东西
        while cnt[item] > k:
            oldest = nums[left]
            cnt[oldest] -= 1
            left += 1  	
        
        # 当前背包安全，更新最大长度
        ans = max(ans, right - left + 1)
        
    return ans
```

`right` 是那只见了什么都要薅一把的右手，`left` 是那只为了保命不停往外甩的左手。

至于效率——每件东西顶多被捡起来一次、再被丢出去一次，时间复杂度 O(n)，空间 O(n)，虽然看起来就像一只塞满颊囊的仓鼠在边跑边掉瓜子。

时间复杂度 O(n)，每件物品顶多被捡一次、丢一次；空间 O(n)，毕竟背包里种类不能无限。

一边捡一边丢，就像仓鼠边跑边掉瓜子。

------

#### 尾声

传送带停了。沙滩上散落着被我左手扔出来的物资，像一条歪歪扭扭的补给线。

系统提示音再次响起，还是一如既往的毫无感情：

> **"挑战通过。背包最长区间：已记录。"**
>
> **"生存评级：初级。"**

初级？我在这破岛上折腾半天，就得了个初级？

我踢开脚边的一个空椰子壳。

罢了，初级就初级吧，好歹还活着。我看向传送带尽头，下一波物资已经蠢蠢欲动。

活着，才有机会捡更多垃圾。
