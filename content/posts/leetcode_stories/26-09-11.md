## 力扣发回血包，你还不接？

读完题干，你沉默了三秒。

> 三位偶数、不能前导零、每个数字用一次、求不同数量。

你开始怀疑自己是不是阅读理解退化了——毕竟上次做力扣还是昨天，而昨天的你还在二叉树上爬。今天它只是数三位偶数。

当你看到数据范围：`3 <= digits.length <= 10`，你悟了。

`digits` 最多 10 个数字，全排列选三个最多 `10P3 = 720` 种。三位偶数从 `100` 到 `998`，总共也就 `450` 个。

今天的力扣，是来给你发回血包的。

它甚至贴心到，把四种经典陷阱都塞进了示例里：

- `[1,2,3,4]` → 12：新手教程关。NPC 站桩让你练平A，有手就能过。
- `[0,2,2]` → 2：边界关。0 想当百位，系统：你当 007 呢？前导零懂不懂？
- `[6,6,6]` → 1：库存关。三个 6 凑一个 666，老六独美。
- `[1,3,5]` → 0：劝退关。全奇数站一起，像极了一排 if 条件全不满足——直接 return 0。

------

既然力扣今天这么坦诚，你也不搞什么组合数学分类讨论了。

**解法一：暴力美学——全排列一把梭**

数据这么小，直接 `permutations` 全排列选三个，拼成数，筛掉前导零，筛掉奇数，最后 `set` 去重。

```python
def totalNumbers(digits: List[int]) -> int:
    return len(set(a * 100 + b * 10 + c 
                   for a, b, c in permutations(digits, 3) if c % 2 == 0 and a != 0))    
```

一行暴力解。属于是"我知道这题很水，所以我也懒得优化"的松弛感。

缺点是"全试一遍"会生成一堆废数——奇数、前导零、重复排列——然后再丢掉。

但话说回来，就 720 种情况，全试一遍怎么了？又不是 720 万种。

**解法二：计数数组——逐位构造，零废操作**

能不能不生成废数？能。

开一个长度为 10 的数组 `cnt`，`cnt[d]` 表示数字 `d` 还剩几个没用。然后逐位选：

- 百位：`1~9`，有库存就选，天然没前导零
- 十位：`0~9`，有库存就选，全场最自由的工位
- 个位：`0, 2, 4, 6, 8`，只从偶数里挑，有库存就计数

选一个扣一个库存，回溯加回来。

每个 `(百, 十, 个)` 组合天然不重复，不需要 set 去重——属于是"我从不内耗，因为我根本不重复"。

```python
def totalNumbers(digits: List[int]) -> int:
    cnt = [0] * 10
    for d in digits:
        cnt[d] += 1
    ans = 0
    for h in range(1, 10):  			# 百位：1~9，不能前导零
        if not cnt[h]: continue
        cnt[h] -= 1
        for t in range(10):  			# 十位：0~9，自由人
            if not cnt[t]: continue
            cnt[t] -= 1
            for u in range(0, 10, 2):  	# 个位：必须是偶数
                if cnt[u]:
                    ans += 1
            cnt[t] += 1
        cnt[h] += 1
    return ans
```

`9 × 10 × 5 = 450` 次操作，常数级复杂度。

今天力扣甚至没给你一个能超时的机会。
