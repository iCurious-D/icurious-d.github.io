## 只要有奇数，就能让全队变成奇数

> 你以为这是一道构造题？不，它其实是一道“找工具人”的社会工程学题。

**第一步：忘掉数字，只看奇偶**

题目给了两种操作：保持原值，或者减去另一个元素。

减法的奇偶性有什么规律？同奇偶相减得偶，异奇偶相减得奇。

数字具体多大根本不重要，真正在干活的只有奇偶性（parity）。

**第二步：一个"工具人"就能把全队 parity 统一改掉**

题目说不同 `i` 可以选同一个 `j`。

这意味着只要 `nums1` 里有一个奇数，就能把它当成全队公用的"工具人"：

- 对每个偶数元素，让它减去这个工具奇数：偶 − 奇 = 奇。

- 对每个奇数元素，啥也不用干，它本来就是奇数。

所以，只要数组里至少有一个奇数，**全队变奇数**，收工。

**第三步：那要是没有奇数呢？**

如果整个数组一个奇数都没有，那说明它本来就是**全偶数**。直接照抄，目标达成。

**结论**

| 奇数个数 | 走哪条路 | 操作                           |
| -------- | -------- | ------------------------------ |
| 0        | 全偶数   | 原数组已经全偶，直接躺平       |
| ≥ 1      | 全奇数   | 找一个奇数工具人，所有偶数减它 |

两种情况覆盖了所有输入，答案恒为 `true`。

```python
def uniformArray(nums1: List[int]) -> bool:
    return True
```

横竖都是赢——**有奇数就全奇，没奇数就全偶**。这题就是个披着构造题外衣的恒真命题。
