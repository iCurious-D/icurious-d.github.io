## 别 DP 了，踢个内鬼就行

你，冒险团团长，手握一份 `nums` 花名册，每个数是队员的能量值。今天要带一支子序列队伍去打 XOR 魔王。

魔王有个被动：队伍 XOR 合体技为 0 就免疫，还会嘲讽你：

> **“你们搁这元素中和呢？？”**

目标只有一个：**带最多人，打出非零伤害。**

------

#### XOR：元素反应引擎

看到‘子序列’别急着上 LIS、DP、双指针——这任务是脑筋急转弯，难度全在名字长。

XOR（异或）就三条江湖规矩：

- `a ^ a = 0`：同属性碰撞，双双湮灭
- `a ^ 0 = a`：加个空气，啥也没变
- `a ^ b = c`：异质融合，炼出新元素

更关键的是，XOR 满足**交换律**和**结合律**——谁站 C 位、谁站角落，合体技的最终威力都一样。所以“子序列”的顺序约束在 XOR 面前就是张废纸，本质就是选子集，想踢谁踢谁。

**破局公式**：记全队总异或为 `total`，踢掉 `xi` 后，剩余异或就是 `total ^ xi`。

> 因为 `total = 其余 ^ xi`，所以 `total ^ xi = 其余 ^ xi ^ xi = 其余`，两个 `xi` 直接湮灭。

这条公式，就是今天的破局关键。

------

#### 点将台：全都要，但别带空气团

你站在点将台上，看着满编队伍，第一反应当然是——全都要！

但先别急，确认一下这是不是一支“空气团”：

```python
if not any(nums):
	return 0
```

如果全员都是 0，非空子序列异或永远是 0，Boss 直接笑纳你的“0 伤害”。没救了，空气团实锤，返回 `0`。

不是空气团？那就有搞头。先把全员拉出来，算一下合体技`total`，然后分两种情况：

1. `total != 0`：那还选啥？整个数组本身就是合法子序列，长度 `n` 直接拉满。这波叫“全都要”。

2. `total == 0`：全体一起上会团灭——合体技被中和成 0。但别慌，队伍里至少有一个非零元素（因为不是空气团）。随便踢掉一个非零的"背锅侠" `x`：`剩余异或 = total ^ x = 0 ^ x = x ≠ 0`——直接活了！长度 `n-1` 就是答案。这波叫 “牺牲一个内鬼，拯救全队”。

```python
def longestSubsequence(nums: List[int]) -> int:  
    # 空气团：全员 0，任何非空子序列 XOR 都是 0
    if not any(nums):
        return 0

    total = reduce(xor, nums)

    # total != 0 → 全都要，返回 n
    # total == 0 → 踢掉一个非零倒霉蛋，返回 n-1
    return len(nums) - (total == 0)
```

复杂度：时间 O(n)，`any` 一趟 + `reduce` 一趟；空间 O(1)，连 DP 表都不用开。

------

#### 尾声

你带着队伍走向魔王。合体技的光芒在每个人掌心汇聚，数字在虚空中跳动，最终停在一个非零值。

魔王脸色一变，像被 `1` 和 `0` 混合双打：

> “不可能！你们不是应该中和成 0 吗？！”

你回头看了一眼队伍，背锅侠已经不在，剩下的人整整齐齐。

> “不好意思，我们刚优化掉一个内鬼。”
