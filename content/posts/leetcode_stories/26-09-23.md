## 赤壁烧烤后，曹操靠滑动窗口逃出生天

赤壁一把火，烧得曹操八十三万大军只剩一地烧烤味。

曹操率残兵败走华容道。泥泞窄路上，`n` 辆辎重车排成一列，每辆车上有 `nums[i]` 斤物资。

路太窄，不能从中间抽车，只能从队首或队尾整车丢下。

前有泥潭，后有追兵。曹操必须恰好丢掉 `x` 斤，问最少丢几辆车。

------

#### 程昱献计

许褚大吼：“丞相！我从车头丢！”

张辽拔刀：“丞相！我从车尾丢！”

程昱一脚踹翻算筹：“住手！你们这么枚举，追兵没到，先把自己人累死。”

曹操阴沉着脸：“那你说怎么办？”

程昱掏出一卷竹简，上面写着四个大字：

> **滑动窗口。**

曹操盯着那四个字，怀疑程昱被赤壁的大火熏坏了脑子。

程昱面不改色：“名字唬人，计策救命。明公，兵法云——**正难则反**。”

曹操眼皮一跳。官渡、乌桓，都是靠这四个字翻的盘。

程昱：“**与其想'从两端丢什么'，不如想'中间留什么'**。总共 `total` 斤，丢 `x` 斤，中间留的就是 `target = total - x` 斤。只能从两头丢，留下的必然是一段连续车队——留的最长，丢的最少。”

曹操拍腿：“妙啊！宁教我负天下人，休教天下人负 `target`！”

程昱：“明公，别中二了，口号喊得再响，关羽也不会少砍一刀。”

曹操假装没听见，手指在竹简上那四个大字上敲了敲：“所以这'**滑动窗口**'，能找到最长的连续车队？”

程昱点头：“右扩左缩，一趟扫完。”

------

#### 滑动窗口

曹操：“来人，上沙盘。”

程昱把两杆小旗往沙盘两边一插：“就两杆旗，一杆 `left`，一杆 `right`。”

- `left`、`right` 圈出一段准备保留的车队。
- `window_sum` 是这段车队的辎重总和。
- `right` 一路往右扩，把车加进窗口。
- 如果 `window_sum > target`，说明留太多了，`left` 往右缩，把左边的车踢出保留区。
- 如果 `window_sum == target`，更新最长窗口长度——窗口越长，丢的越少。

许褚听完，若有所思：“所以 `right` 是探路的，`left` 是嫌多的？”

程昱看了他一眼：“你居然听懂了。”

张辽问：“等等，要是 `total < x` 呢？”

程昱：“那还滑个屁。死局，直接返回 `-1`，准备跟关羽拼命。”

曹操问：“要是 `target == 0` 呢？”

程昱：“一辆不留，轻装跑路，答案 `n`。”

曹操又问：“那要是找不到呢？”

程昱：“`ans` 还是 `-1`，回去接着被关羽砍。”

曹操：“……程昱，你说话真难听。”

程昱：“明公，实话都难听，`O(n)` 才动听。”

```python
def minOperations(nums: List[int], x: int) -> int:
    total = sum(nums)
    if total < x:
        return -1

    target = total - x
    left = 0
    window_sum = 0    
    max_len = -1
    for right, num in enumerate(nums):
        window_sum += num
        while window_sum > target:
            window_sum -= nums[left]
            left += 1
        if window_sum == target:
            max_len = max(max_len, right - left + 1)
            
    return len(nums) - max_len if max_len != -1 else -1
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`，快到像绝影马起飞。

------

#### 关羽验窗

华容道尽头，关羽横刀立马。

曹操：“云长，今日我走不了？”

关羽：“军师说你会滑动窗口，我不信。你算出来了？”

曹操：“`total = sum(nums)`，`target = total - x`，最长连续子数组和等于 `target`，答案 `len(nums) - max_len`。”

关羽沉默三秒：“……你走吧。我不杀滑窗之人。”
