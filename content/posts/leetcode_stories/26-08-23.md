## 聚会杀手锏2.0！求和游戏教你三秒看穿胜负

> 朋友，上次用《石子游戏》在聚会上大杀四方后，你的朋友是不是已经对你产生了警惕，甚至开始用“数学题”来防你？别慌，今天安利一款进阶版——《求和游戏》（LeetCode 1927）。它不再是“先手必胜”的傻瓜模式，而是需要你在开局前动动脑子，用小学数学判断这局能不能接。学会之后，你依然是聚会上最靓的“人形计算器”。

------

#### 游戏规则（升级版）

这次咱们不玩石子，改玩“数字填空”，一张纸一支笔就能开局。

让你的朋友在纸上写下一串**由数字和问号组成的字符串**，除了**长度必须是偶数**，其它随意发挥。比如 `"?1?2"`、`"??90"`、`"1??9?0"`  等等，都行。

写好后，你（Alice）和朋友（Bob）轮流把 `?` 填成 `0~9` 里任意一个数字，你（Alice）先手。

等所有问号都填完，把**左半边数字加起来**，**右半边数字加起来**：

- 如果相等，朋友（Bob）赢；
- 如果不等，你（Alice）赢。

听起来很公平？其实只要掌握下面的**三秒心算大法**，你就能在开局前判断自己能不能赢。

------

#### 必胜操作手册（请严格照做）

**第一步：心算三个数**：

- 假装不经意地**扫一眼左半边**：把左半边已知数字加起来，记作 `left_sum`。  
- **扫一眼右半边**：把右半边已知数字加起来，记作 `right_sum`。
- **数个问号**：数一数**左半边的 `?`** 比**右半边的 `?`** 多了几个，记作 `gap`（如果左半比右半少，`gap`就是负数）。

**第二步：判断能不能接这个局**：

- 如果 `gap` 是**奇数**，恭喜，这局你（Alice）稳赢，请放心大胆地开始。
- 如果 `gap` 是**偶数**，再算一下 `left_sum - right_sum` 是否等于 `-9 * (gap // 2)`。
  - **不等于**：你稳赢，请开始你的表演。
  - **等于**：赶紧找借口换边，比如“这局你先当 Alice 体验一下”，或者立刻尿遁。

------

#### 为什么心算能定胜负？

核心就一句：**最终左右两边差多少，取决于 初始差值 + 每个问号填的数字。**

- 初始差值：`d = left_sum - right_sum`
- 左半问号填 `x`，差值增加 `x`
- 右半问号填 `x`，差值减少 `x`

下面分两种情况，把 判断的底牌摊开来看。

**情况一：`gap` 是奇数 → 总问号数是奇数**

左右两边的`?`的数量差`gap`  和总问号数的奇偶性相同（ `qL + qR` 和 `qL - qR`  同奇偶）。所以 `gap` 是奇数，等价于总问号数是奇数。

总问号数是奇数，你（Alice）先手——这就意味着**最后一个问号永远是你的**。

想象游戏打到最后一轮：你的朋友（Bob）费尽心思维持平衡，把左右差值调到了某个`cur`，而你拿起最后一个 `?`，微微一笑—— 0~9 有十个选择，能让 Bob 赢的只有一个，你闭着眼睛都能避开。

所以只要总问号数是奇数，先手 必胜。这就叫“**最后一个问号 = 最终话语权**”。

**情况二：`gap` 是偶数 → 总问号数是偶数**

总问号数是偶数时，你的朋友（Bob）作为后手，拥有了“**配对反制**”的机会。他的最优策略就是把所有问号两两配对，然后跟着你走。具体怎么配？分两类：

- 第一类：**左右各一个 `?` 配对**：

  如果左半和右半都有问号，朋友（Bob）就可以把一个左半问号和一个右半问号配成一对。
  你填左半 `x`，Bob 就填右半也为 `x`；你填右半 `x`，Bob 就填左半也为 `x`。
  这一对的净贡献 `x - x = 0`，完全抵消，等于没填。

- 第二类：**同一侧多出的 `?` 配对**：

  如果左右问号数量不等——也就是上面数问号得到的`gap`（`左半?数 - 右半?数` ，左半多时`gap` 为正，右半多时`gap` 为负)，Bob 就可以把同一边的这些多余问号两两配对。
  你填其中一个为 `x`，Bob 就填另一个为 `9 - x`。这一对的贡献就被焊死为 **9**。

  **为什么 Bob 最优策略是把这一对贡献焊死为 9？**

  因为 Bob 的目标很明确：不管你在一个问号里填什么，他都要能在另一个问号里填一个合法数字，让这两个数字的和始终保持一个固定值。这样他才能把局面牢牢攥在自己手里。

  那这个固定值选多少好？
  数字范围 0~9。如果固定和小于 9，比如 8，你填个 9，Bob 想稳就得填 -1，超纲了；如果固定和大于 9，比如 10，你填个 0，Bob 就得填 10，也超纲了。只有固定和等于 9 时，无论你填 0~9 里的哪个数字，Bob 要填的另一个数都还在 0~9 里面——你填 0 他补 9，你填 9 他补 0，你填 5 他补 4。无论你怎么挣扎，这一对加起来永远是 9。

左右配对：贡献 0；同侧多余配对：多出来的那一侧有 `|gap|` 个问号，能配 `|gap|/2` 对，每对贡献 9；左半多则总贡献为 `+9*(gap//2)`，右半多则为 `-9*(gap//2)`，统一写成 `9 * (gap // 2)`。

所以Bob 能把最终差值锁定为：

```text
最终差值 = (left_sum - right_sum) + 9 * (gap // 2)
```

Bob 想赢，就需要这个最终差值等于 0，也就是需要：

```
left_sum - right_sum == -9 * (gap // 2)
```

如果这个等式成立，Bob 就能靠“9-x 魔法”强行逼平，所以你只能找个理由跑路，或者含泪把 Alice 这个先手位子让给他。

如果这个等式不成立，Bob 的“9-x 魔法”就是纸老虎，你（Alice）必胜。

这就是你需要在开局前心算三个数的全部理由。

#### 实战演示

假设朋友自信满满地写下 `"?3295???"`，长度 8，左右各 4 位。

你先别急着填，心里盘算一下：

- 左边 `"?329"`：`left_sum = 3 + 2 + 9 = 14`，问号数`qL = 1`
- 右边 `"5???"`：`right_sum = 5`，问号数`qR = 3`
- `gap = 1 - 3 = -2`（偶数）
- 条件：`-9 × (gap // 2) = -9 × (-1) = 9`
- `left_sum - right_sum = 14 - 5 = 9`

`9 == 9`，条件成立！说明 Bob 能逼平。这时你当先手就是送人头，要赶紧面不改色地说：“这局我让你先手体验一下。”

但如果你的朋友写下的是 `?1?2` 这样的字符串：

- 左半 `"?1"`：`left_sum = 1`，问号数 1
- 右半 `"?2"`：`right_sum = 2`，问号数 1
- `gap = 1 - 1 = 0`（偶数）
- 条件：`-9 * (0 // 2) = 0`
- `left_sum - right_sum = 1 - 2 = -1`

`-1` 不等于 `0`，所以先手必胜。你可以放心开局（第一手直接把左半 `?` 填成 `0`），然后享受胜利。

#### 写在最后（附代码）

下一次聚会，当别人还在纠结谁先手谁后手时，你已经优雅地心算三秒，然后决定这局是接还是溜。

**奇数直接赢，偶数算差值。** 从石子游戏到求和游戏，数学永远是你最靠谱的队友。

```python
def sumGame(num: str) -> bool:
    half = len(num) // 2
    left_sum = sum(int(c) for c in num[:half] if c != '?')
    right_sum = sum(int(c) for c in num[half:] if c != '?')
    questions_gap = num[:half].count('?') - num[half:].count('?')
    
    # 返回 True 表示 Alice 赢，False 表示 Bob 赢
    return questions_gap % 2 != 0 or left_sum - right_sum != -questions_gap // 2 * 9
```
