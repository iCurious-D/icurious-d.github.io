## VPS：Very Painful Statements

如果你曾满怀信心点开一道名叫《有效括号的嵌套深度》的题，然后被 VPS、depth、123456789 三连击到怀疑人生，那么恭喜，你不是一个人。

力扣 1111 的题面干了这些事：

先用三条递归规则定义什么叫**有效括号字符串（VPS）**，再用三条递归规则定义什么叫**嵌套深度 `depth`**，然后举了 `"()()"`、`"()(()())"`、`")("`、`"(()"` 四个例子。

到这里还没进正题。接下来它掏出一个跟括号毫无关系的东西——序列 `123456789`，开始教你什么叫“**子序列可以不连续**”：`A = {1, 3, 5, 7, 9}，B = {2, 4, 6, 8}，对应输出 [0,1,0,1,0,1,0,1,0]`

一道括号题，拿数字序列做示例，生怕你语文和数学一起挂科。

最后终于提出要求：把 VPS 拆成两个不相交的子序列 A 和 B，两者都必须是 VPS，让 `max(depth(A), depth(B))` 最小，返回一个 01 数组，标记每个括号的归属。

整体翻译一下：

> 把一个括号串里的每个括号分给 `0`、`1` 两个人，要求两人手里的括号（按原顺序）仍然是合法括号串，并且两人中"嵌套更深"的那个尽量浅。

VPS，全称 Very Painful Statements，没毛病。

------

#### 核心：一对括号，同一层

吐槽完毕，开始干活。这题说穿了就两句话：**一对括号不能拆，相邻楼层要分家。**

用 `depth` 记录当前套到第几层，也就是还有几个左括号没等到它的右括号。

拿 `(())` 走一遍：

- 第一个 `(`：`depth` 变成 1，第 1 层；
- 第二个 `(`：`depth` 变成 2，第 2 层；
- 第一个 `)`：当前 `depth=2`，第 2 层，记完再降到 1；
- 第二个 `)`：当前 `depth=1`，第 1 层，记完再降到 0。

注意：**一对匹配的括号，左右两端永远在同一层。**

左括号在第 `d` 层开门，中间不管怎么套娃，它的右括号也一定在第 `d` 层关门。

现在要把这些括号分给 `0`、`1` 两个人。要求：

1. 两人手里的括号（按原顺序）仍然是**合法**括号串；
2. 两人中嵌套深度最大的那个**尽量浅**。

要合法，**一对匹配的括号必须给同一个人**。不然 `(` 给 0，`)` 给 1，两边都落单，直接出局。

要尽量浅，**相邻层最好分给不同的人**。第 1 层给 0，第 2 层给 1，第 3 层给 0……每个人手里最多只剩隔层的括号，深度直接砍半。要是第 1、2、3 层全塞给 0，他手里还是 `((()))`，深度一点没降，白拆。

怎么做到“不拆对，还分开相邻层”？

一个简单又稳的构造：**按层号的奇偶分**。奇数层给 0，偶数层给 1，或者反过来——答案天生镜像，不唯一。

同一对括号层号相同，奇偶相同，自然进同一个人手里；相邻层奇偶不同，自然分给不同人。这波操作，既保全了括号的完整，又避免了某个人深度过载。

> 至于为什么这是最优？
> 简单来说，假设最深的嵌套链有 `k` 层。这 `k` 层不管怎么分给两个人，总有一个人至少拿到 `⌈k/2⌉` 层。这些层在原串里层层相套，到了那个人手里依然层层相套。所以他的深度至少是 `⌈k/2⌉`。这是理论下界。
> 奇偶分层正好达到这个下界：一个人拿奇数层，另一个人拿偶数层，最大深度就是 `⌈k/2⌉`。

不是贪心，不是运气，是精确最优。

```python
def maxDepthAfterSplit(self, seq: str) -> List[int]:
    ans = []
    depth = 0
    for ch in seq:
        if ch == '(':
            depth += 1
            ans.append(depth & 1)
        else:
            ans.append(depth & 1)
            depth -= 1
    return ans
```

注意：右括号先记录当前层，再减 `depth`。因为匹配的右括号和左括号得同层。

当然也有等价写法：

```python
def maxDepthAfterSplit(self, seq: str) -> List[int]:
    ans = []
    depth = 0
    for ch in seq:
        if ch == '(':
            ans.append(depth & 1)
            depth += 1
        else:
            depth -= 1
            ans.append(depth & 1)
    return ans
```

两种都行，但别混着写。混着写括号会精神分裂。

时间复杂度：`O(n)`，扫描一遍。

空间复杂度：`O(n)`，输出数组；额外空间 `O(1)`。栈？不需要真的开栈，一个 `depth` 整数就是栈的灵魂。

一行流也能写，但建议只在朋友面前装，不要在面试官面前抖：

```python
def maxDepthAfterSplit(seq: str) -> List[int]:
    return [(d - (c == ')')) % 2
            for d, c in zip(accumulate(seq, lambda d, c: d + (c == '(') - (c == ')'), initial=0), seq)]
```
