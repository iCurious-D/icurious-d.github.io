## n 个小兵，有台词的只有俩

一排数字小兵，从 `0` 号位到 `n-1` 号位依次排开。系统告诉你：这排小兵里有一个 **战力天花板**（最大值）和一个 **战力地板**（最小值），你的任务是把这两位请出队列。

但规则极其不友好：你只能从 **队伍最前面** 或 **最后面** 动手，不能直接闪现到中间抓人。

这俩人站得越靠里，你要顺带“请走”的无辜群众就越多。于是你陷入沉思：怎么用最少的操作，把这两位天选之人送走？

------

**第一步：锁定两个主角**

`n` 个元素，真正有戏份的只有最大值和最小值，剩下 `n-2` 个全是群演——没台词、没特写、删的时候顺路领盒饭。

```python
i, j = sorted((nums.index(min(nums)), nums.index(max(nums))))
```

`min` + `index` 最多把数组扫 4 趟，但每趟都是 C 级快跑——多跑的路，靠腿速赚回来了。

**第二步：清场方式只有三种**

只能从两端删，所以打法就三种：

- **全头推**：从队头一路删到 `j`。 `i` 在 `j` 左边，最大值最小值一起拿下。代价 `j + 1`。
- **全尾推**：从队尾一路删到 `i`。 `j` 在 `i` 右边，两个目标一同送走。代价 `n - i`。
- **前后夹击**：对头删到 `i`，队尾删到 `j`，中间群众原地吃瓜。代价 `i + 1 + n - j`。

就像塔防清怪：左路平推、右路平推、或者两队同时包夹。哪种最省？`min` 一下，直接收工：

```python
return min(j + 1, n - i, i + 1 + n - j)
```

**边界自己会闭环**

数组只有一个元素时，这位老哥一个人扛下了所有——既是最大值又是最小值：`i = j = 0`，不用特判，公式一算，自己把自己处理明白了。

```python
def minimumDeletions(nums: list[int]) -> int:
    n = len(nums)
    i, j = sorted((nums.index(min(nums)), nums.index(max(nums))))
    return min(j + 1, n - i, i + 1 + n - j)
```

时间 O(n)，空间 O(1)。

------

**懒人版 vs 强迫症友好版**

上面的代码偷了个懒：`min` 扫一趟、`max` 扫一趟、`index` 再各扫一趟——四趟跑完，主打一个量大管饱。

强迫症表示一趟必须搞定：

```python
def minimumDeletions(nums: list[int]) -> int:
    n = len(nums)
    min_idx = max_idx = 0
    
    for idx, v in enumerate(nums):
        if v < nums[min_idx]:
            min_idx = idx
        if v > nums[max_idx]:
            max_idx = idx
    
    i, j = sorted((min_idx, max_idx))
    return min(j + 1, n - i, i + 1 + n - j)
```

一趟是省了，但每一步都是慢悠悠的 Python 字节码。跑四趟的 C 级飞人 vs 跑一趟的步行选手，实测谁快还真不好说——性能优化，玄学是也。
