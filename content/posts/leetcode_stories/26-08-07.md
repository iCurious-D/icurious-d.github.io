## 赛博地牢 II：无零绝境

#### 序章：黑曜石门

黑曜石门通体流淌着暗红色的光脉，像是某种古老心脏的搏动。

你收回铁剑——剑身上的 `while True` 咒文已经黯淡，像是被这扇门上的威压强行沉默。你伸手触摸门楣，冰冷刺骨的铭文直接投射进你的意识：

> **隐藏试炼：无零秘境**
> `num` 是一串长达二十万位的巨型整数。找到一个 **大于等于** `num` 的最小整数，要求：
> · 所有数位 **禁止出现 0**。
> · 所有数位的乘积能被 `t` 整除。
> · 若此世间不存在此数，献上字符串 `"-1"`。

你握紧拳头，感受到一股从地牢深处涌上来的压迫感。无零——意味着“每十个数必踩中 0”的取巧技巧彻底失效——这不是地精那种杂兵，这是真正的守关者。

石门中央裂开一道缝，红光喷涌而出，在半空中凝成一座由黑曜石和数字符文构成的巨型魔像。魔像睁开四只眼，每只眼睛里都旋转着一个数字——**2、3、5、7**。

它的胸口悬浮着一颗脉动的能量核心—— `t`。暗红色的光从核心中涌出，沿着符文回路流向四肢百骸，像血液，又像正在执行编译的代码。而它的脚下，散落着无数断裂的铁剑残骸——那些是曾试图用暴力枚举硬刚、最终被 TLE 超度后留下的墓碑。

魔像开口，声音像一千块石板互相摩擦：“凡人以铁剑与蛮力，也敢挑战乘积法则？”

你深吸一口气，将铁剑插回腰间，双手结印——铁剑上的 `while True` 应声碎裂，碎片剥落——新的铭文从剑芯中亮起——`greedy_construct()`

"三招。" 你举起剑，剑尖直指 Boss 核心，"够送你去存档点了。"

------

#### 第一招：质因剥离

你第一剑没有砍向 Boss——你双手握剑，猛地把剑插入地面。

```python
tmp = t
for p in 2, 3, 5, 7:
    while tmp % p == 0:
        tmp //= p
if tmp > 1:
    return "-1"
```

黑色地面以剑尖为中心轰然炸裂，金色裂缝犹如蜿蜒的蛛丝，沿着 2、3、5、7 四条质数脉络追向 Boss 脚下，顺着它的双腿攀爬而上，最终在胸口的能量核心处骤然收束。

Boss 低头看着爬满胸口的金色裂纹，四只瞳孔同时收缩。

> **“你……在探查我？”**

“对。” 你没有拔剑，双手仍按在剑柄上，“让我看看你到底是什么玩意儿做的。万一你核心掺了 11 或者 13 这种杂质，那这场架根本不用打——法则层面无解，我直接甩个 `-1` 走人，你自个儿在这儿当行为艺术。”

Boss 的能量核心顺着裂缝反向涌入你的感知——`256`。8个2，没有任何超出 2、3、5、7 范围的异质藏在里面。

“挺纯的嘛。”你将剑从地面拔出，带起一串火星，金色裂缝随之熄灭，“八层护甲，全是 2。是个正经 Boss。”

Boss 冷哼一声，声波震得胸口残留的金光四散。

> **“哼。就算你看穿核心又如何？我的身体才是你要超越的基准数字！”**

魔像双臂一振，体表的数字纹路骤然亮起—— `num = 988`，每一位数字从最高位到最低位依次排列，在暗红色的光芒中铺展成一面巨盾。每一个数字都在跳动，仿佛在挑衅你。

你看着那面盾，嘴角微微一扬。

“确实。知道你足够 2 是一回事，怎么用数位 凑出这些 2 是另一回事。”你转了转剑腕，“所以才需要第二招。”

------

#### 第二招：逐位削甲

你没有急着砍。你开始**走位**。

沿着由 num 数字构成的巨盾，你**从高位到低位逐位走过**，剑尖不疾不徐地划过盾面上的每一个数字——每走一位，`gcd` 就是这一位的数字能从剩余护甲里精准削掉的部分，`left_t[i]` 记录削完前 i 位后，Boss 核心的护甲还剩多少层。

同时你紧盯每一位数字，撞见 0 直接插标记。无零是死规则，0 就是这面盾的裂缝，必须从这里开刀。

```python
n = len(num)
left_t = [0] * (n + 1)
left_t[0] = t
pos = n - 1

for i, c in enumerate(num):
    if c == '0':
        pos = i
        break
    left_t[i + 1] = left_t[i] // gcd(left_t[i], int(c))
    
if left_t[n] == 1:  # boss放水，num的数位之积已经是 t 的倍数
    return num
```

剑尖划过盾面，每经过一位数字，便留下一道淡金色的浅痕——

```
【战斗日志·慢动作回放】
num = "988", t = 256

剑锋划过每一位：
  位置0: left_t[0] = 256（起始八层甲）
  位置1: '9' → gcd(256, 9) = 1  → left_t[1] = 256 ÷ 1 = 256 （1毫无战斗力）
  位置2: '8' → gcd(256, 8) = 8  → left_t[2] = 256 ÷ 8 = 32  （8削掉三层！）
  位置3: '8' → gcd(128, 8) = 8  → left_t[3] = 32 ÷ 8 = 4    （8削掉三层！）

left_t[3] = 4 ≠ 1 → num本身削到头了还剩 4，护甲没碎！
num没有0，pos = 2（最后一位），从这里往前改。
```

预计算完毕。你转过身，面向 Boss。

Boss 闷声笑了起来：

> “你以为我会放水吗？太天真了！怎么，你的剑只会摸不会砍？”

“摸是为了砍得准。”你把剑换到左手，活动了一下右手腕。

“听好了——现在我将**从末位开始，一位一位往前填**。每一位都从当前数字往上加，加完把后面全部换成最能削甲的组合，也就是从低位开始填，从 9 往下降着填，直到我的数字能把你这八层甲削的一块不剩。”

说完，你反手一剑，从末位开削。

```python
ans = list(map(int, num))

for i in range(pos, -1, -1):
    for ans[i] in range(ans[i] + 1, 10):
        t_now = left_t[i] // gcd(left_t[i], ans[i])
        k = 9
        for j in range(n - 1, i, -1):
            while t_now % k:
                k -= 1
            ans[j] = k
            t_now //= k
        if t_now == 1:		# 质因子全部凑齐！
            return "".join(map(str, ans))
```

剑光闪烁，一个个数字在你的贪心算法下跳跃。

```
【战斗日志·逐位贪心构造】

第 3 位（末位），原数字 = 8
→ 试 9: t_now = left_t[2] // gcd(32, 9) = 32 // 1 = 32，剩余护甲32 → 失败
→ 已试到 9，末位单挑无解！

第 2 位（中位），原数字 = 8
→ 试 9: t_now = left_t[1] // gcd(256, 9) = 256 // 1 = 256
      → 末位 从 9 往下降：9 不行，8→gcd(256,8)=8，剩 32 → 失败
→ 已试到 9，中位无解！

第 1 位（百位），原数字 = 9
→ 9 已是最大，无法增大。百位直接跳过。

三位全部试完，没有一个组合能让剩余护甲归零。
```

你叹了口气，甩了甩剑上沾着的数字碎屑：“啧。你 num 太短，t 的护甲又太厚。”

Boss 双臂抱胸，四只眼睛眯成嘲讽的弧度。

> “你跳来跳去，还不是在我的长度里碰壁？三招？我看你再跳一百下也是白费力气！**”**

你把剑往肩上一扛，笑了。

“我说三招，又没说非要在你的长度里解决。你这num 不够长？我来给你接一段。”

------

第三招：破界重构

你抬头望天，剑尖指向穹顶。

一道金色的光柱从剑尖冲天而起，轰然撞上地牢的天花板，光纹沿着穹顶向四周蔓延，像在虚空里撕开了裂缝。

“原长度无解？那就**不陪你玩原长度**。”你将剑往下一划，金色光柱从穹顶劈落，在盾牌旁边硬生生劈出一个新的数字位，“我自己造一个更长的——”

```python
ans = []
for i in range(9, 1, -1):
    while t % i == 0:
        ans.append(str(i))
        t //= i
return "".join(ans[::-1]).rjust(n + 1, '1')
```

“从 9 往下降，能合并就合并。”你开始逆向构造，剑尖在空中飞速刻画，“三个 2 合一个 8，再来三个 2 合一个 8，剩下两个 2 单独合不成了，凑一个 4。从小到大排列——4、8、8——再加一个 1 在前面当新位，1488。”

```
【战斗日志·破界重构】
t = 256 = 2×2×2×2×2×2×2×2

逆向合成：8(三个2) + 8(三个2) + 4(两个2) → [8, 8, 4]
反转排列：4 → 8 → 8 → "488"
原 num 长度 = 3 → 新数字长度 = 4 → 前面补 1 → "1488"
```

一道数字光带从你剑尖射出，由 1、4、8、8 组成，每一个数字都燃烧着金色的质因子之光。光带瞬间缠住魔像，乘积法则被反向满足——不是你去适应它，而是你造出了一个让它无法抗拒的数字。

Boss 的护甲开始一一碎裂。它仰头看着你，四只眼中的数字疯狂旋转，发出齿轮卡壳般的刺耳声响。

> “不可能……原长度无解，你居然自己加位数？！”

“原长度找不到，不代表更长的长度找不到。”你把剑往地上一插，双手拄着剑柄，“规则只说了大于等于 num，没说不能比 num 长。前面补 1，后面用质因子拼出最小组合。这招叫破界重构——贪心构造的最后一块拼图。”

你将剑一横，“三招，打完收工。”

光带收紧。魔像身躯上的数字符文逐一爆裂，四只眼中的 2、3、5、7 依次熄灭。

它发出最后一声混合着不甘与金属摩擦的咆哮，化作满地黑曜碎石，随即化成数据碎片，被地牢的回收系统吞没。

------

#### 尾声：

黑曜石门的残骸缓缓消散，新的传送阵在碎石堆后亮起，蓝光温和而稳定。

你把剑插回腰间，长长地吐了口气。

三招。第一招看穿底牌，第二招在规则内穷尽所有可能，第三招突破维度一击定局。不是靠蛮力，不是靠运气——靠的是把问题一层层剥开、在每一步都选最优的那份冷静。

你低头看了看手中的铁剑。剑身上的 `greedy_construct()` 铭文不知何时多了一行小字，像是通关后自动刻上去的成就印记：

> **“所有质因子问题，本质都是背包问题——你只是换了种方式打包。”**

你忍不住笑了，然后提了提背包，大步迈入传送阵。

身后，地牢的灯光一盏盏熄灭。黑暗中，隐约传来一声轻响——一种很微妙的动静，像是什么东西刚刚解锁。
