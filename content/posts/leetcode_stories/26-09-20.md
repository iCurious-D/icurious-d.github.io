## 下次看到123，不要只想到'木头人'

复习下 ASCII：

小写字母在 ASCII 里是连续的，从 97 到 122：

> **'a' = 97**
> 'b' = 98
> ...
> **'z' = 122**

对于字符 `c`，它距离 `'a'` 有多远？

> ord(c) - ord('a') = ord(c) - 97

按题意模拟，它的反转位置就是：

> 26 - (ord(c) - 97)
> = 26 - ord(c) + 97
> = 123 - ord(c)

更妙的是，`chr(123)` 是 `{`，也就是小写 `z` 后面那个字符：

> 'z' = 122
> **'{' = 123**
> '|' = 124
> '}' = 125
> '~' = 126
> DEL = 127  # 不可打印控制字符

下次看到 `123`，不要只想到“木头人”，它还是 `{`，是反转字母表的起跑线。

```python
def reverseDegree(s: str) -> int:
    return sum((ord('{') - ord(c)) * i for i, c in enumerate(s, 1))
```

时间复杂度：`O(n)`，空间复杂度：`O(1)`，生成器非常环保。

既然是 ASCII 算术，那最后必须来点 ASCII 八卦。

**1. ASCII 三大地标**

> ord('0') == 48
> ord('A') == 65
> ord('a') == 97

经典三件套：

- 数字字符转数字：`ord(c) - 48`

- 大写字母转 0~25：`ord(c) - 65`
- 小写字母转 0~25：`ord(c) - 97`

**2. 大小写只差 32**

> ord('a') - ord('A') == 97 - 65 == 32

二进制看更明显：

> 'A' = 65  = 0b1000001
> 'a' = 97  = 0b1100001

只差 `0b0100000` 这一位，也就是 `32`。所以有各种魔法操作：

```python
ord(ch) | 32            # 变小写
ord(ch) & 0b11011111    # 变大写
ord(ch) ^ 32            # 切换大小写
```

另外提一句，`32` 在 ASCII 里是空格。

**3. ASCII 的最后一个码位给了 DEL**

标准 ASCII 是 0 到 127，共 128 个。

最后一个码位`127`，是 `DEL` 控制字符，二进制：`127 = 0b1111111`。

七个 1，全打孔——早期纸带用全打孔表示删除，因为全打孔能盖住任何已打的孔。

所以 ASCII 里的删除字符 `DEL` 的码位是 127。

**4. `:-)` 表情包的远古祖先**

1982 年，卡内基梅隆大学的 Scott Fahlman 看着 BBS 上纯文字吵架太容易友尽，于是提议：

> :-)   表示玩笑
> :-(   表示严肃

从此，人类在网络上吵架终于有了表情护体。
