## “连续”两个字都怼到脸上了，还能不用滑动窗口？

你是一个光荣的打工人。这个月的工作日志被系统无情地压成一串二进制：`1` 是加班日（凌晨两点的灯是真的亮），`0` 是没加班的日子——在老板眼里，没加班就是在摸鱼。

月底绩效面谈，老板翘着二郎腿，鼠标滚轮在你的日志上滚来滚去，突然停住，抛出个奇葩需求：

> "给我截**一段最短的连续天数，恰好包含 k 个加班日**。一样短的话，给我**字典序最小**的那段——别问为什么，我有我的审美。"

你心里万马奔腾——最短？恰好 k 个？多一天说你效率低，少一天说你态度差。还整个"字典序最小"？老板的审美比他的排期还抽象。

但面上你依然镇定，嘴角自动挂上职业假笑："好的老板，懂了。"

回到工位，你盯着那串由你亲手创造的打卡记录：怎样从自己的摸鱼史里，拼出一份最体面的加班证明？

------

#### 一：定位加班日（枚举 1 的位置）

老板的诉求很明确：找一段**最短的连续子串**，里面恰好有 `k` 个 `1`。

最短意味着什么？意味着**能删的全删**。开头是 0？砍——长度变短，1 的个数不变。结尾是 0？同理，直接砍。

至于字典序最小——虽然 `'0' < '1'`，但在“最短优先”的铁拳下，开头的 `0` 根本活不过一秒。

于是你悟了：**最短美丽子串，必然以 1 开头，以 1 结尾。**两头必须是硬货——就像写周报：开头"深度参与核心项目"，结尾"保障线上稳定运行"，中间哪怕全是"配合支持"，头尾两句硬话也能撑住你的体面。

所以策略就一句话：只记加班日（`1`）的位置，然后每次取连续的 k 个加班日，框出首尾，就是候选。

1. 先扫一遍日志，把所有 `1` 的下标存进 `ones` 列表。
2. 如果 `len(ones) < k`，直接返回 `""`——加班天数根本不够，绩效面谈怕是要变成离职面谈。
3. 遍历 `ones`，每次取**连续 `k` 个**加班日：
   - 截出子串 `s[ones[i] : ones[i+k-1]+1]`，长度就是 `ones[i+k-1] - ones[i] + 1`。
   - 如果这段比当前最优解更短，或者一样短但字典序更小，就更新答案。

```python
def shortestBeautifulSubstring(s: str, k: int) -> str:
    # 把加班日的位置全部找出来
    ones = [i for i, c in enumerate(s) if c == '1']
    if len(ones) < k:
        return ""  # 加班天数不够，老板很生气

    min_len = float('inf')
    result = ""

    # 每次框住连续的 k 个加班日
    for i in range(len(ones) - k + 1):
        left = ones[i]
        right = ones[i + k - 1]
        sub = s[left:right + 1]
        length = right - left + 1

        # 长度更短，或者长度相同但字典序更小
        if length < min_len or (length == min_len and sub < result):
            min_len = length
            result = sub

    return result
```

复杂度？`ones` 最多 n 个，遍历一遍 O(n)，每次切片比较 O(n)，总共 O(n²)。`n ≤ 100` 时随便跑。

#### 二：滑动窗口（双指针）

你盯着解法一的代码，总觉得哪里能再顺一点——先扫一遍收加班日 `1` 的下标，再每 `k` 个拉出来比，就像在日历上先把每个加班日圈出来，再一段段量距离。能用，但两趟活拆着干，多少有点憨。

打工人的直觉告诉你：能一遍扫完的事，凭什么要两遍？

你要找的就是**一段连续区间**——"连续"两个字都快怼到脸上了，这不就是**滑动窗口**的活吗？一个窗口在日志上从左滑到右，右手往前探，左手见机收缩，最优解自己就浮出来了。

直接安排双指针：

- **右指针（right）**：不断向右扩展，把新的一天纳入窗口。
- **左指针（left）**：负责收缩。核心就一个 `while` 循环。左边是摸鱼日（`0`）？删掉，它不影响加班数，留着只会把窗口撑胖；加班天数超了 `k`？从左边开始删，直到加班数回到 `k`。

窗口内恰好有 `k` 个加班日时，这段就是候选答案，和当前最优比一比：先比长度，再比字典序。

```python
def shortestBeautifulSubstring(s: str, k: int) -> str:
    if s.count('1') < k:
        return ""  	# 加班天数不够，面谈变离职

    result = s  	# 初始化为整个字符串，后面不断缩小
    cnt = 0   		# 窗口内加班天数
    left = 0

    for right, c in enumerate(s):
        cnt += int(c)  # 右指针纳入一天

        while cnt > k or s[left] == '0':
            cnt -= int(s[left])
            left += 1

        # 恰好 k 天加班，更新答案
        if cnt == k:
            sub = s[left:right + 1]
            if len(sub) < len(result) or (len(sub) == len(result) and sub < result):
                result = sub

    return result
```

双指针各走一遍 O(n)，但每次切片比较 O(n)，严格来说还是 O(n²)。不过 `n ≤ 100`，随便造。

滑动窗口的精髓，就是**左指针永不走回头路**。这简直是打工人的理想状态——做过的事别反刍，摸过的鱼别回头。
