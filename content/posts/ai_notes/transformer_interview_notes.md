## 为什么应用工程师也要懂 Transformer

AI 应用工程师的面试，「会不会调 API」只是门槛，真正拉开差距的是**对模型行为有解释能力**：为什么这个 Prompt 在这个模型上效果好？为什么长文本成本爆炸？为什么微调会过拟合？

这些问题的答案都在 Transformer 的原理里。本文按面试高频顺序，把核心知识点串成体系。

## Attention：一切的起点

自注意力的核心思想：**序列中每个 token 的动态表示，由它与所有 token 的相关性加权聚合而来**。

计算步骤：

1. 每个 token 通过三个矩阵投影得到 Q（查询）、K（键）、V（值）
2. 注意力分数 = Q 与所有 K 的点积，除以 \\(\sqrt{d_k}\\) 缩放
3. Softmax 归一化成注意力权重
4. 用权重对 V 加权求和，得到该 token 的新表示

\\[ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V \\]

**为什么除以 \\(\sqrt{d_k}\\)？** 维度越大，点积的方差越大，softmax 输入值过大时会进入饱和区，梯度消失。缩放把方差拉回 1，稳定训练。

**为什么用点积不用余弦相似度？** 点积在矩阵运算上极其高效（一次 GEMM 完成所有 token 对的相似度），这是 Transformer 能被工业界大规模采用的关键。

## 多头注意力：MHA → MQA → GQA

### MHA（Multi-Head Attention）

把 QKV 拆成 h 个头分别计算再拼接。直觉：不同头关注不同的关系（语法、指代、位置……）。计算量和参数量都随头数线性增长。

### MQA（Multi-Query Attention）

所有头共享同一个 K 和 V，只有 Q 是多头的。**大幅降低推理时的 KV Cache**（降为原来的 1/h），但模型质量有损失。

### GQA（Grouped-Query Attention）

折中方案：h 个头分成 g 组，组内共享 KV。Llama 2 用 g=8 的 GQA 在质量和效率间取得平衡，也是目前主流开源模型（Llama 3 等）的选择。

**面试常见追问**：「为什么要做 KV Cache？」——推理时逐 token 生成，每个新 token 都要和之前所有 token 做注意力，把之前的 K/V 缓存起来避免重复计算。KV Cache 大小与序列长度、层数、头维度成正比，长文本推理时内存会成为瓶颈，这就是 MQA/GQA 的动机。

## 位置编码：模型怎么知道顺序

注意力本身**对位置无感**（把输入打乱顺序，输出只是对应打乱），所以必须注入位置信息。

### 绝对位置编码（Sinusoidal）

原始 Transformer 用正弦/余弦函数编码位置，加在输入 embedding 上。优点：外推性好（可推广到训练时没见过的长度）；缺点：相对位置关系隐式。

### 可学习位置编码

把位置编码做成可训练参数。GPT 系列早期使用。缺点：长度固定，超出训练长度直接失效。

### RoPE（旋转位置编码）

目前 LLM 主流（Llama、Qwen、GLM 等）。思想：**把位置信息编码成向量空间的旋转**——不同位置的 token 乘以不同的旋转矩阵。

两个重要性质：

1. **相对位置天然建模**：两个 token 的点积只依赖它们的相对距离，而不是绝对位置
2. **长度外推**：配合 NTK 等缩放技巧，可以把训练长度扩展到 4 倍甚至更长

### ALiBi

不加位置编码，而是在注意力分数上直接加一个与距离成比例的惩罚项（距离越远扣分越多）。训练简单、外推性强，但效果不如 RoPE 灵活。

## 其他关键组件

### 前馈网络（FFN）

每个 token 独立经过两层线性 + 激活（GELU/Swish），扩展维度通常是 4× 或 8/3× 隐藏维度。**Transformer 的知识主要存储在 FFN 参数里**——这是「模型知识在哪」类问题的标准答案方向。

### LayerNorm：Pre-LN vs Post-LN

- **Post-LN**（原始 Transformer）：残差连接之后再归一化。训练需要 warmup，深层网络不稳定
- **Pre-LN**（GPT/LLM 主流）：归一化放在残差之前。训练更稳定，可以不 warmup，成为 LLM 标配
- **RMSNorm**：LayerNorm 的简化版，去掉均值中心化只保留缩放，计算更快，Llama 系使用

### 训练细节（面试常问）

| 细节 | 作用 |
|------|------|
| Warmup | 训练初期学习率从小渐增，避免早期梯度不稳定破坏模型 |
| 余弦退火 | 学习率按余弦曲线衰减，训练末期精细收敛 |
| 梯度裁剪 | 限制梯度范数，防止长文本样本引发梯度爆炸 |
| AdamW | 带权重衰减的 Adam，权重衰减与 L2 正则解耦，更有效的正则化 |
| Dropout | 随机丢弃神经元，防止过拟合；现在大模型预训练阶段用得少了 |

## 高频面试题速查

**Q：Transformer 的时间复杂度？**
A：自注意力对序列长度 n 是 \\(O(n^2)\\)（每个 token 与所有 token 算注意力）。这是长文本的核心瓶颈，衍生出稀疏注意力、FlashAttention、线性注意力等优化方向。

**Q：为什么 Transformer 比 RNN 好？**
A：RNN 串行计算、长距离依赖靠隐状态传递（容易遗忘）；Transformer 完全并行计算、任意两位置直接交互（路径长度 O(1)）。代价是 \\(O(n^2)\\) 复杂度。

**Q：Softmax 的梯度消失问题？**
A：当 \\(QK^T\\) 数值过大时 softmax 输出接近 one-hot，梯度接近零。缩放因子 \\(\sqrt{d_k}\\) 就是为了把输入方差控制在合理区间。

**Q：为什么现在大模型用 GQA 而不是 MHA？**
A：KV Cache 是长序列推理的主要内存开销，GQA 共享 KV 头，把 Cache 缩小 g/h 倍，推理吞吐大幅提升，质量损失可接受。

**Q：LoRA 通常加在哪些层？**
A：注意力层的 Q/K/V/O 投影矩阵（有时含 FFN）。原理详见[模型微调实战](/posts/ai_notes/lora_finetuning_practice/)一文。

## 小结

- Attention 公式要能默写，\\(\sqrt{d_k}\\) 的缩放理由要能讲清
- MHA → GQA → MQA 是「质量 vs 效率」的权衡谱系，动机是 KV Cache
- RoPE 是当前主流位置编码，能讲清「相对位置 + 外推」两个性质即可
- Pre-LN 与 RMSNorm 是 LLM 稳定训练的基础配置

这些知识点不要求推导，但要求**能用自己的话讲清动机与权衡**——这正是应用工程师面试考察的深度。
